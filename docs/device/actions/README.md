# 动作的系统配方

每个文件是一族动作：**怎么在这个 ROM 上把它做出来**（入口类、方法、intent 形态、权限闸门、踩过的死路）。
「这个动作在模块里怎么接进来」在 `../../runtime/`，「这一族里哪些场景系统自己支持」见下表。

| 文件 | 收什么 |
| --- | --- |
| `system.md` | 电源菜单、侧键场景表（13 个场景的调用目标）、`oplus:` 动作族、小布识屏 |
| `toggles.md` | 手电筒、免打扰、系统开关的读写分工、NFC |
| `audio.md` | 音量、响铃档位与切换那一下的振动 |
| `brightness.md` | 亮度百分比、自动亮度下的改写、控制中心那条为什么不动 |
| `capture.md` | 截图（含个别机型改走 `ScreenshotHelper`）、录屏、录音 |
| `launch.md` | 打开应用：多开选择器、快捷方式被 BAL 拦、转场动画全链路 |
| `voice.md` | 唤醒小布、屏幕翻译、灵感语音 |
| `lock-screen.md` | 锁屏左下 / 右下那两颗快捷功能 |
| `feedback.md` | 执行提示的通道：Toast 限流、为什么改由注入侧弹、转发卡在主 looper |

节号沿用拆分前的编号，索引见 `../README.md`。
