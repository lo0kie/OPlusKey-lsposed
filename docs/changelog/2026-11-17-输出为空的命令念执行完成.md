# 输出为空的命令念「执行完成」

## 修

### 修：开着「用输出代替命令名」，没有输出的命令仍念命令名

- 现象：无线调试那条命令（两句 `settings put`）开着这一位，提示里一直是命令名；
  其余几条（`am start`）正常 —— 区别只在它跑成功时**一个字都不打印**；
- 根因：空输出那一支回落到命令名，于是「开」与「没开」长得一模一样，这一位看起来彻底没用；
- 现在空输出念「执行完成」（新增 `command.output_done`）：`NoticeSpec` 的 `fallback` 改名
  `noOutput`，两个调用点各自决定念什么 —— 侧键那条一律念「执行完成」，测试那条按**这一条命令
  自己的** `showOutput` 给（开着「执行完成」、关着命令名，与按侧键同一个读法）；
- 失败那一侧不补这一句：`publishOutput` 多收一个 `ok`，为假时一个字都不念
  （执行失败已经报过一条，再说「执行完成」是假话）；有输出时照旧念输出、成没成都念 —— 那串字
  本身可能正是出错原因；
- 发提示时多打一行「输出 N 行、ok=…」，下次再问「为什么念的是这一句」有据可查。

### 修：固定深浅主题下首帧整页先按系统深浅画出来

- 建页那一步只能读系统那一档深浅，配置读回来之前 `chrome.dark` 停在系统值：选了固定浅色而系统
  是深色时，首页大卡会先是一整块暗色、再随修正变亮；
- `applyPageLoad` 在 `loaded` 翻真**之前**先按新配置跑一次 `syncNight("配置读回")`，
  页面组合出来的第一帧就是用户选的那一档。

### 修：几颗新字形漏登记图标选择器

- CI 的 `check-icon-selector.py` 红了：`step-into` / `clock` / `sort-ascending-shapes` /
  `sort-descending-shapes` / `photo-off` / `color-filter` 只在别处被引用，没进 `FluidIcons.ALL`
  —— 编译照过、界面照跑，只是胶囊图标选择器里点不到那几颗（用户能选的清单就是 `ALL`）；
- 按字母序补进清单（250 颗），几颗字形的 `outline.*` import 一并补上；
- 顺带清掉 `ThemeMonet` 撤走后残留的 `outline.Palette` 未用 import（detekt 报的）。

## 加

### 加：「多条命令逐条提示」那一行

- 公共设置页「按键行为」卡与独立设置页各多一颗开关（`step_notice`）：只在「执行时提示」不是
  「不提示」时出现，显隐走行自己那套进出场（连分隔线一起收）；
- 独立设置里每一位都能单独覆盖（`OwnField.STEP_NOTICE`）：`OwnSettings` / `OwnSettingsValues` /
  `KeyConfig` / `ComboKey` 各多一位，与其它开关同一档（只在 `useOwnSettings` 开着时算数）；
- 图标是 `step-into` 逆时针转 90°（`rotatedIcon`）：转成正向后读作「一条链上按顺序一段一段过去」；
- 开关先只落盘：**执行侧尚未接**，这一版拨开与关着行为一样（一条链仍只念一句命令名）；
- 配置版本 86：`GlobalDto` / `KeyDto` / `ComboDto` 各多一位 `step_notice`（缺键即关）。

### 加：组合两列小标题的「更多」里有排序

- 「等待组合」「按住组合」小标题行尾改成「更多 + 已用 / 上限」，几何与「命令步骤」那条同一份
  （`SectionTitleTrailingMore`）；
- 菜单三档互斥、打勾当前一档：不排序（`clock`，副标题「按创建时间」）、有顺序在前
  （`sort-descending-shapes`）、无顺序在前（`sort-ascending-shapes`）；菜单标题写「排序」
  （`combo.sort_title`），不是列名 —— 它就是从那一列的小标题点开的；
- 排的是**显示次序**：`cfg.combos` 自己不动，行首「第几组」跟着改后的次序重数，同档内仍是创建先后；
- 两列各存一份，**跟着配置文件走**（`GlobalConfig.waitComboSort` / `holdComboSort`，存文本 id）：
  换一份配置就换一套显示偏好，与配色 / 语言同一档；只在界面层读、不进广播；
  三档的枚举落在界面层（`ui/model/page/ComboSort.kt`），认不出的 id 落回「不排序」。

### 加：「减少界面图标」

- 「外观」卡多一颗开关（`reduce_icons`，图标 `photo-off`），默认关；
- 开着时卡片行（普通行 / 开关行 / 滑杆行 / 可展开行）、菜单行、以及「支持的命令格式」那几行
  的行首字形一律不画（`LocalReduceRowIcons` 页面级给一次，拨完整页当场重画）；
- 留着的只有三处：**应用图标**（`startIcon` 自己画的，它是内容不是装饰）、**网格**与**候选抽屉**
  （后者用新加的 `CardRow.Item.keepIcon`，抽屉里那颗图是这一步的身份）；
- 图没了那一列，**分隔线左缩一并收掉**：卡片内（按还有没有图标列算）、菜单行间那条线、
  格式卡内、滑杆轨道那四处；
- 菜单行收起行首之后，**选中那一档的对勾移到行尾**（`reduceIcons && selected` 才让库画）；
- 纯显示项、只在界面层读，所以只落盘、不进广播；配置版本抬到 88。

## 改

### 改：主题只管深浅，「使用 Monet 配色」拆成外观卡里的一行开关

- 「主题」菜单收回三档：跟随系统 / 浅色 / 深色（`AppTheme` 只剩 `fixedDark` 一位）；
- 外观卡紧挨着「主题」多一行开关「使用 Monet 配色」（图标 `color-filter`，三个交叠的圆）：
  开了整页那套色板换成系统按壁纸生成的那一套，关着仍是 COUI 底子 + 只换强调色族；
- 深浅与配色各占一行、自由组合 —— 原先挤在同一个单选框里，得为每种搭配列一行；
- 判据从「主题档自带的 `monet` 位」换成配置里那一位，由 `PageContent` 顺着
  `LocalMonetColors` 递下去：顶栏 Tab 行、浮层菜单、确认弹窗、输入框、首页状态卡、命令格子各读它；
  `colorsOf` / `accentSwatch` 也随之收「是不是 Monet」这一位布尔，不再收整档主题；
- 配置多了 `global.monet_colors`：`ConfigCodec.VERSION` 89 → 90，
  `tools/config-shape.txt` 刷到 90 / 168 字段；老文件里 `monet` / `light_monet` / `dark_monet`
  三个主题值读进来那一刻翻成「三档 + 这一位」（见 `ConfigDto` 的 `legacyThemeCode` /
  `legacyThemeMonet`），用户原来选的那一档不会丢；
- 「主题」那一行的当前值回到只写深浅（`浅色`），配色由下面那一行开关自己说。

### 改：组合成员分隔符改成「和」，一句话里的先后念「后 / 再」

- 成员之间那一个符号从写死的「×」改成**按当前语言取**（`comboMemberSeparator`，中文「和」、
  英文 `and`）：`COMBO_PAIR_SEPARATOR` 连同它的两个伴生常量一起删掉，调用点都改过来
  （车票名字流、列表行、顶栏、回执、编辑页、绑定目标、HostLink 的落点名）；
- 「按住组合」那句话从「按住 A 后再按 B」改成「按住 A 按 B」（`combo.mode_hold`）；
- 一句话场合里按顺序的成员念「A 后 B 再 C」（英文 `A then B then C`）：
  第一段用「后」（`combo.ordered_between`）、第二段起用「再」（`combo.ordered_again`），
  由 `comboOrderedLabelOf` / `orderedWaitSentenceTemplate` 统一给 —— 顺序选择器的排列行、
  编辑页的名字行、顶栏那一格都用这一套（原先是一串箭头 `A → B → C`）；
- 应用条件（「前台应用」多选那种 `微信 × QQ`）**没有动** —— 那里的 `×` 是「或」，
  与组合键的「一起按」不是一回事（注释里补了这一句）。

### 改：等待组合的列表标题一律念「和」，先后交给副标题

- 列表行标题不再按顺序换连接词：`A 和 B`、`A 和 B 和 C`（按顺序也是这一种）；
- 副标题不再把先后念一遍：按顺序写「从左往右依次按下」（新增 `combo.order_ltr`），指给人看标题
  那几个名字的次序；不分前后顺序那一档写「不分前后顺序」；
- 「不分顺序」在顺序选择器里一并改成「不分前后顺序」（含那两句「已经加过…」的原因）；
- 回执 / 提示 / 弹窗标题那些**一句话**场合不受影响，按顺序的仍念「A 后 B 再 C」。

### 改：按住组合的列表标题固定成「A 按住后 B 和 C」，先后交给副标题

- 标题从「按住 A 按 B 后 C」改成「A 按住后 B 和 C」（`combo.mode_hold_ordered`，模板带空格），
  成员之间一律「和」；**不分前后顺序那一档也念同一句** —— 两档标题一样，按不按先后全看副标题；
- 副标题不再把成员名念一遍：顺序那一档写「按住首键后从左往右依次按下」
  （新增 `combo.order_ltr_hold`），不分前后顺序那一档写「不分前后顺序」；
- 顶栏那句与列表标题**逐字相同**（`holdSentenceTemplate(..., holdThen = true)`）：那里只有一句话的
  位置，不再为它换连接词；回执仍是模板里那个「按」；
- 顶栏副标题、绑定目标 / 条件目标 / 分支归属那几处「这是哪一组」的文案改走 `comboLabel`
  （按顺序那档要念「A 后 B 再 C」，只拼成员名读不出先后）。

### 改：组合列表行标题里只有连接词小一号

- 标题改成按段拼（`comboTitleParts`：键名一段、连接词一段），键名照标题字号，`按住` / `后` / `和`
  缩到 0.95（`COMBO_CONNECTOR_SCALE`）；
- 比例乘在标题自己的字号上，页面字号缩放与系统字号一起跟；纯文字那一份（`comboTitleText`）由同一份
  分段拼出，只给无障碍 / 日志用。

### 改：主题 / 强调色 / 语言 / 执行时提示 / 切换配置 / 作者的当前值写到行尾

- 这几行的当前档位从标题下的副标题挪到行尾，紧挨选择器：先看行名，再看右边「现在是什么」；
- 行尾这一组按整行启用态一起压暗（新组件 `RowEndSummary`，文字与选择器同一格、同一档颜色）；
  执行时提示那一行（`NoticeModeRow`）一并改过来；
- 其余行不受影响，副标题仍留在标题下面。

### 改：卡片、浮层菜单与弹窗的圆角各加一档

- 行卡片圆角收到一处（`PageMetrics.CARD_CORNER` 16dp，库默认 12dp）：行卡片、首页「已激活」卡、
  动作格子、已保存命令卡、「支持的命令格式」卡与格子的焦点圈都按它画；选中行那圈内边框按同一
  半径重算（末行框角与卡片轮廓同心）；
- 浮层菜单面板 16dp：界面库补丁 `0016-custom-popup-corner-radius.patch` 把面板与投影的圆角开成
  参数，磨砂取样、底色与描边同用这一档；
- 通用弹窗（确认 / 起名 / 选择器）从库默认 19dp 加到 24dp（`DIALOG_CORNER`），比页内卡片再大一档。

### 改：「跟随系统显示大小」去掉，页面大小只由「界面缩放」一档说了算

- 「更多选项 → 外观」少一行「跟随系统显示大小」；原来那根滑杆改名「界面缩放」（英文 `UI scale`），
  一直露着，不再跟着开关进出场；
- 页面密度基准改成**宿主那一份**（100% = 宿主页面的标准大小），再乘 `pageScale / 100`；
  不再读系统那份 `displayMetrics`，于是页面不再随系统「显示大小」变 —— 要多大自己调；
- 配置 `global.follow_display_size` 删掉：`ConfigCodec.VERSION` 88 → 89，
  `tools/config-shape.txt` 刷到 89 / 167 字段；老文件里那个键按未知键丢掉，无行为迁移；
- `PageIcons.TextSize` 随之删掉（只有那一行用）。
