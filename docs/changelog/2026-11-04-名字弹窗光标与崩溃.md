# 名字弹窗的光标与崩溃

### 修：名字弹窗自动聚焦后光标停在开头

- 焦点判据从「这一层自己有焦点」改成「焦点在我下面某处」：修饰符挂在输入框外面那一层，真正拿到焦点的是库内部的节点，原来那条判据一次都不成立。
- 挪光标的按键事件不再发给不在窗口里的 View：那一层拿到的不是真窗口时只记一行 w 并放弃，不再静默空发。

### 修：弹窗里点一下输入框就崩宿主进程

- 弹窗正文不再把 `LocalView` 换成脱离窗口的 View：输入框的光标 / 选区手柄走 Compose 的 `Popup`，拿不到 `ViewTreeLifecycleOwner` 会在挂窗口那一刻抛异常，宿主进程整个崩掉。
- 触觉作用域只保留在浮层菜单那一列；弹窗里库自带的振动改由各控件自己收口（开关、滑杆、勾选框）。

### 改：顶栏圆键的描边再压淡一档

- 圆键描边的不透明度从 `dividerLine` 那一档的一半收到三成，压在磨砂顶栏上只剩「这儿有个圆」；这一个数抽成 `HEADER_BORDER_ALPHA`，以后调浓淡不用碰颜色角色。

### 改：弹窗「取消」按钮降一档

- 「取消」的底色比原先那档再淡一档（非 Monet 档 15% → 10%），Monet 档的 `secondaryContainer` 压到七成浓度，不再与右侧动作项争视线。

### 改：顶栏、固定带、选择应用页的左右留白统一到卡片那一档

- 顶栏的标题、返回键、右侧按钮组三个水平边距都改成 `PAGE_MARGIN`（原为库默认的 16dp），与卡片外边距、固定带里的分段控件对齐。
- 固定带与「选择应用」页的搜索框跟着回到 `PAGE_MARGIN`，整页只剩一根左边缘。

### 改：所有浮层菜单都接预测返回

- 浮层菜单（各页 `⋮` 菜单、长按菜单、二级菜单，统一从 `MenuPopup` 出）登记「这一退归我」，系统预测返回手势不再被整段吞掉，而是交给菜单自己的返回处理器收尾 —— 与底部抽屉同一档。
- 确认窗不登记：它要给个答复，只走一次性收起。

### 修：Monet 下选了预设色却是深蓝

- 「跟随系统」主题里选蓝 / 绿 / 橙 / 紫 / 玫红等预设色时，不再沿用系统那一档调色风格（`TONAL_SPOT` 会把种子彩度压掉），固定按保留彩度的 Fidelity 重推整套，预设色才真的像它自己。
- 顺带删掉那段只为读系统调色风格而存在的 JSON 映射（对比度本来就按 SDK 取）。

### 重构：五处重复实现收成一份

- 兜底守卫三份并成一份：`XLog.guard` 多了「日志末尾说明」与「失败时本处收尾」两个口子，`BackInterception` 的系统回调与 `ComboActions` 的写盘守卫不再各带一份 `try/catch`。
- 同包广播的注册收成 `Context.registerLocalReceiver`：网络代取、导出日志、链路自检、收集按键四处不再各写一遍 `RECEIVER_NOT_EXPORTED` 的注册与失败处理。
- 弹窗按钮条的「取消 / 确定」改成参数默认值，六处逐字相同的文案不再各传一遍。
- 浮层菜单的「开合 + 锚点」收成 `MenuState` / `rememberMenuState()`，配一个只在开着时求值行表的 `PageMenu(state)` 重载；组合列表筛选与变量类型两处改用它。
- 「添加按键」「重命名」两个只差一句标题的转发层删掉，两个调用点直接写 `NameDialog`（各自的说明搬到调用点）。

### 修：配置层把「读不懂」当成「没有」的六处（数据会被覆盖）

- 切换配置时命令库 / 变量表：任一槽**读不懂就整趟不动**，不再按「老配置没这份」去拿另一份盖掉；变量表补上与命令库对称的「第二步失败还原目标槽」。
- 导出配置：命令库读不懂时**放弃导出**，不再静默拿当前这份顶上去（那样导出来的备份里是别人的命令）；`ProfileCommands` 新增三态 `load`。
- 导入配置：新槽也落一份空变量表，导入的那份不再继承上一套的计数。
- 当前配置读不懂时**拒绝切换**，不拿目标内容盖掉那份还能救的文件。
- 变量文件里有条目读不懂时整份按「读不懂」处理，不再丢掉坏条目后仍报成功（下一次写盘就会把那几颗永久抹掉）。
- 导入命令库时「有元素却一条都认不出」判为读不懂，不再当空表落盘（那会把用户的命令库清空）。

### 修：配置 / 日志 / 注入的一批隐蔽缺陷

- 变量写盘不再每次盖掉开机标记：`setvar` 只改值、不代表「这一轮开机的 resetOnBoot 已重置」，先 setvar 再重启会把待办的重置抹掉；只有落地重置那次显式盖章。
- 跨进程变量锁改 `tryLock`：`lock()` 会在另一进程被冻结时一直等，卡住按键线程；拿不到就「这次不串行」。
- 槽列举把 `.bak` / `.new` 也算「槽还在」：只剩 `.bak` 的配置不再从列表消失、槽号不再被复用。
- 判据日志方向两处：合成按键那条从 `d` 提成 `w`；注入结果码不再把成功码 0 记成「被拒」（真正失败的那一次原来一行都不打）。
- 日志环形缓冲不再靠独立计数器：并发下计数会偏，改为「先加再按 `buffer.size` 裁」，上界真正受控。
