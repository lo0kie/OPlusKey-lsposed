# 2026-11-11 · 界面重复实现收成一份、挑应用页五处对齐、热点端到端验过

### 多选应用那一趟的大标题改成「多选应用」

- 给条件挑前台应用时，顶栏原本写「打开应用」，读起来像「点一下就打开它」；那一趟点一行是勾选、右下角才落盘，现在写「多选应用」（新增 `app_picker.multi_title`，中英两档同步）。
- 三档判据与行尾图标、点行行为同源：多选 → 「多选应用」，结束 → 「结束应用」，其余 → 「打开应用」。

### 挑应用页的标签：去掉「用户」，「系统」不再跟着开关走

- 应用名后面不再标「用户」—— 用户级就是默认，没有标签即用户应用。`app_picker.tab_user` 因此没有调用点了（键与两条译文暂时留着）。
- 「系统」那一枚此前跟着「显示系统应用」开关走，而「结束应用」那一趟会把系统应用一并列出来（`includesIconless` 里 `stopApp` 强制为真）—— 那一趟开关关着就一枚标签都没有。现在只要这一行是系统应用、且这一趟列得出系统应用就标。
- 「模块」仍压过「系统」；「不可打开」前面那档间隙的判据跟着改成「前面画过任意一枚」。

### 没有下级页的那几趟，挑应用行尾换成空心圈

- 「结束应用」与场景 / 条件里的多选应用都只认应用本身、点一行就是选中，箭头（「进下一级挑界面」）在那几页没有对应去处：行尾改成空心圆圈（`TileUnchecked`），与选中态的实心圆勾配成同一套单选说法。
- 判据与「点这一行做什么」共用 `appOnly`，不另立一套；要挑界面的入口（网格、场景里单个动作）仍是箭头。

### 勾着「显示系统应用 / 失效应用」时，应用列表等全量再上屏

- 进「选择应用 / 结束应用」不再先把默认档（有启动图标的 + 模块 + 分身）铺出来：那两档开着时，列表会先短后长地闪一下，现在整趟查完才换掉加载态。
- 判据仍是 `includesIconless` / `includesUnopenable`：两档都关着时默认档就是这一页要显示的全部，照旧先上屏。

### 挑应用页的标题与包名各写明「一行」

- `CardRow.Item` 新增 `titleMaxLines` / `summaryMaxLines`（默认仍是 3 行），挑应用页两者都传 1：那一行定高 64dp 只为让应用图标整高，行高按「一行标题 + 一行副标题」算。
- 此前靠父级高度把多出来的行裁掉 —— 系统字号一调大，裁的位置就变。现在标题、包名都单行超出省略，约束从「高度偶然裁出来」变成写明的。

### 弹窗正文、边距与捐赠窗外壳归位

- 按键页「启用 / 停用」那一问的正文改走 `DialogBody`：短句居中、长句左对齐，超出可滚 —— 手写一个裸 `Text` 时正文一长就把两颗按钮顶出可见区。
- 命令详情浮层的 24dp 左右内缩改走 `dialogSideMargin()`，正文左缘与标题严格对齐。
- 捐赠窗从自建 `OverlayDialog` 改走 `FrostedDialog`（`centered = true`）：磨砂与三区区距同全项目其他窗，内容槽不再自己补上下 24dp。
- 浮层菜单与「更新说明」的滚动条宽度合成 `SCROLLBAR_WIDTH`（12dp，落在 `PageMetrics`）。

### 空态摆位收成一层

- 五处空态 / 加载态（浮层、列表项、已保存的命令、变量列表、场景块）的摆位合成 `CenteredInInsets`；滚动页那三处的「视口 − 顶栏 − 页底留白」合成 `visibleAreaHeight`，居中壳再包一层 `VisibleAreaCentered`。
- 各页让掉的档不同，都写在调用点：已保存的命令与场景块让页底留白（`PageScrollColumn` 自带那一档）；变量列表那一页的留白挂在滚动内容末尾、空态那一支自成一屏，所以只让顶栏 —— 多减一档会把中线抬上去半档。

### 小标题行尾「更多 + 计数」收成一支

- 命令详情、命令步骤、场景块三处合进 `SectionTitleTrailingMore`：菜单在前、计数在最后，中间 `SECTION_TITLE_COUNTER_GAP`。
- 要在菜单**前面**再放一格（场景块那半句「已停用」）由调用点自己先画 —— 那一格是那一页自己的话，不属于「菜单 + 计数」这套几何。

### 行内「标题 + 副标题」收成一份

- 卡片行、可展开行、滑杆行的字号 / 字重 / 2dp 行距合进 `RowTitleLine` / `RowSummaryLine`；`ExpandableRow` 的私有 `TITLE_SUMMARY_GAP` 与滑杆里写死的 `2.dp` 一并删掉。
- 行数上限、是否跟随内容动画、量不量溢出仍归各调用点 —— 那是这一行自己的排版，不是「这一行长什么样」。

### 行尾「已停用 + 勾选框」收成一支

- 按键列表两处（侧键 / 自定义键）、组合按键一处逐字相同的「已停用 + 勾选框」合进 `DisabledStateWithPick`，与既有的 `DisabledStateWithArrow` 并排。

### 行首图标三档色与卡片三档底色各收成一份

- `rememberRowIconColor` 增加 `override` / `selected` 两档，顺序是 禁用 > 选中 > 随机色；删掉 `CardRow` 的私有版本，绑定格改调同一支。
- 命令卡与绑定格的三档底色合进 `appCardColors()`（绑定格的内容色是动画值，留形参）。

### 零碎真源合一

- `MAX_NAME_LENGTH` 两处合一（留在 `PageNameDialog.kt`，命令页改为引用）。
- 浮层菜单小标题的计数拼接改走 `titleWithCount`，与分组标题那一族同一句。
- 命令名称那栏删掉输入框之后的第二道折行（`CommandLibrary.sanitizeNameInput`）：到那一步已无换行可折，语义还与输入框那层的 `foldLineBreaks` 不同。

### 删掉零调用点的 `IconAction`

- 步骤行早已改用 `StepButton`，`IconAction` 与 `ICON_ACTION_ICON` 一并删除；`ICON_ACTION_SIZE` 保留（步骤按钮的尺寸账还在用它）。
- `PageSheet` / `HomeHeaderMenu` / `DisabledHint` 里指向它的注释改成指向 `SheetAction` 或 `STEP_BUTTON_GLYPH_RATIO`。
