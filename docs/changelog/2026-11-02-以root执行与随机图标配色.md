# 以 root 执行、随机图标配色与提示链路收口

### 加：以 root 执行成了每条命令自己的开关

- 单条命令页新增「命令设置」小标题与「以 root 执行」开关：开 = 只走 `su`（拿不到 root 就这一次失败，不退回 `sh`），关 = 只走 `sh`（不申请 root）。副标题把两种走法都写清楚，不替用户判断。
- 这个开关存在命令上、随命令一起落盘：命令库与配置的序列化都带上 `root`（缺键按「以 root」读，老配置行为不变），配置版本 19。
- 执行侧按这条命令自己的档位起进程，不再「先 su，失败再退 sh」试两次；草稿的「改过没有」判据也算上这一档。
- 失败提示分两档：走 `sh` 失败报「此命令需要 root 权限」；`su` 起不来 / 权限被拒报「「手势体感」没有 root 权限」。

### 改：单条命令的图标按 su / 非 su 分两颗

- 以 root 执行的单条命令用盾牌（`ShieldCode`），不申请 root 的用带框终端（`Terminal2`）—— 命令列表里一眼能看出哪几条会提权。
- 取字形的判据收在 `commandIcon` 一处：命令列表卡片、摘要与步骤行里引到单条命令的那一行、以及「添加命令」抽屉的候选行都按被引用命令自己的档位取，三处不会再各长一套。

### 加：随机图标配色

- 「更多 → 外观」新增「随机图标配色」：开着时每颗图标按名字落到一个固定色（11 个色相，明暗各一档饱和度 / 亮度），关掉再打开换一批；关着时图标仍跟随主题色。
- 覆盖卡片行、开关行、滑杆、网格格子、绑定格、菜单行与各类标签；选中的、禁用的、危险色的行不参与随机色（那几档的颜色本身在表达状态）。
- 新增全局配置 `icon_tint_seed`（0 = 关），换一批就是换一个种子。

### 修：提示（Toast）连按时只看到旧内容 / 有几下没提示

- 提示改由**注入侧**弹：宿主把「弹这句话」发给注入侧，注入侧用系统身份（包名 `android`，持有免限流权限）弹 —— 系统 toast 按**包**限流（3 条 / 20 秒、5 条 / 42 秒、6 条 / 68 秒），宿主自己弹到那个密度后面几下必被丢。
- 每按一下都完整弹一条：注入侧每次都新建、不 cancel 上一条，让它排队；同一句话 1 秒内不重复弹（长按连发时同一条命令会连着报同一句）。
- 空文案不再弹，并撤掉该提示位上原来那条（避免一条已经过期的说明挂着）。
- 系统侧那两条硬约束（每包限流的三档阈值、显示中不推进队列）连同排查判据一起写进 `docs/device-findings.md`。

### 改：弹窗壳统一成「头 / 正文 / 底」三段

- 面板改成自绘：正文拿「剩下的高度」、超高时自己滚，标题与按钮始终可见；三段之间的间隙同一档。
- 行高与平台文字样式统一（去掉字体额外留白、首行与末行按位置修剪），要点与多段落文案不再顶到行首 / 塌到最后一行下面。
- 危险动作的按钮红底白字。

### 改：命令页

- 「命令名称」小标题行尾加字数计数，全屏编辑弹窗里同一套；「命令列表」两段小标题去掉条数计数（网格本身就摆着有几条）。
- 多条命令的步骤卡改用通用卡片列（分隔线与首尾圆角由列表统一算），「添加命令」也成了这张卡的一行；排序态的行尾按钮与退场动画收口，退场中的行不再占位。
- 命令格式：输入框里已经写了别的格式前缀时，点新格式只**替换**前缀，不再往后拼一串。
- 「命令列表」「命令详情」小标题行尾那颗「更多」贴齐右边线，与左边那颗类型图标对称。
- 换 tab 不再「键盘弹一下又没了」：点过格式行之后那个「请把焦点还给输入框」的举手是页面级的，切走再切回来会按旧计数再抢一次焦点 —— 改成兑现一次就清掉。
- 右下角那颗 FAB 恢复滑入滑出（此前是硬切，进出像闪了一下），与其它页同一档。

### 修：空命令被报成「这条命令已经不在了」

- 空命令（单条没正文 / 多条没步骤）与「库里查不到这个名字」原来是两条不同的提示，但空的 `cmd:` 引用（后面没写名字）落到了后者上——按下去让人去命令库里找一条根本没写进名字的东西。现在这一档报「这条命令是空的」。
- 空命令的判据收成一处（`Command.hasContent`），按键派发、`cmd:` 引用、「测试」按钮三条入口共用；执行侧不再各写一遍。
- 「测试」按钮先判空再派发：空命令当场说「这条命令是空的」，不再先弹「已触发」再让执行器报一次失败。

### 改：「添加命令」抽屉

- 候选行改用项目通用的卡片行（行高、分隔线、按下反馈、选中态配色与各页一致），抽屉不再自绘一行。
- 条件执行那一支的候选表多列「无操作」（它在场景里是一档真取值）；条件没选动作时行上写「无操作」并给它自己的图标。

### 修：选择应用页的小标签与标题中线不齐

- 去掉标签那档手工下沉：标签与标题现在都按字形实测居中，同一行里两者的墨迹中线才对得上。

### 加：按住滚动条滑块振一下

- 「选择应用」「应用组件」两页的滚动条，按到滑块那一下走通用振动通道；按在轨道空白处不振（那里按下去什么都不会发生）。

### 改：列表与标题的几何收口

- 卡片里行首有图标列时，行间分隔线从**标题左缘**起；行首图标右侧补一档间距，不再左宽右窄。
- 小标题行尾那一格按「更多」按钮的几何对齐（条件执行页那一处贴着卡片右缘、不缩）。
- 菜单里的小标题：缩进与行首图标列对齐、文字补光学修正（行盒居中改成墨迹居中）、上下留白改成一档 6dp 且不区分首条（首条原本只在上沿多 10dp，看着上多下少）；小标题**下面**那条分隔线左端放宽到面板自己的内边距（连行首图标那一格一起画，右端与左右留白照旧）。
- 组合键菜单里「已经收下的那颗键」用带圈数字，与旁边有外框的字形同一体量；侧键手绘图形的竖条描边收细一档。

### 改：禁用态的说明落到「这一行」

- 某颗键被停用时点它，说的是「该键已停用、去菜单里启用」，而不是整页那句通用的「现在改不了」；页面级的说明仍作兜底。
- 浮层菜单里的触觉统一走通用通道，弹层里的按住反馈与页面里那套不再分两条路。
- 按键的增删改提示补齐中英文案（添加、重命名、删除、启用 / 停用）。

### 改：文案与杂项

- 提示里给键名加引号按语言走（中文「」，英文 ｢｣），不再写死中文括号。
