# 锁屏快捷、图标重绘与首页命令页改版

### 新增：快捷功能里的「锁屏快捷」一格（二级菜单选相机 / 计算器）

- 点这一格弹二级菜单，「相机」「计算器」两行。两档走的是**锁屏左下 / 右下那两颗快捷功能**的同一入口：锁屏下按侧键直接出界面，不用先解锁；解锁状态下按就是普通打开。
- 相机那一档与「打开应用」选相机的区别：带上了系统那颗快捷功能会发的锁屏来源标记，相机才按「从锁屏进来」的那一支收界面。
- 计算器那一档的关键在启动方式：它只在收到系统那条 action 时才允许显示在键盘锁之上，「打开应用」那样起会被锁屏盖住。
- 两档都不会把打开的那一屏留在最近任务里。
- 熄屏下按也能用：这两档会先把屏幕点亮，再起界面（别的内置动作不点屏）。
- 菜单两行用相机 / 计算器自己的字形，那一格本身是一道闪电（「按一下就开」）。

### 改：首页顶上那四件东西收成一张「模块状态」卡

- 模块状态、版本、两条提示、主开关原来是三四块，现在并成最上面这一张：左上是大字状态，底下跟版本与一句说明，右上角压一颗同色水印。
- 状态四档各有一句：「已激活」「已关闭」「未激活」「检查中」。前两档不是一回事 —— 一个是用户自己关的（不报错、不给红），一个是开着却没在系统里生效（那是故障）。
- 主开关不再单独占一行、也没有那颗开关：**点这一整块就是开关**。
- 原来首页那条更新提示条与顶部那条常驻提示并进卡里：真故障排在「跑着旧版」前面说，只剩旧版影子时按系统侧 / 宿主侧分别说「重启手机」还是「重启服务」，同一件事只说一句。
- 「已关闭 / 检查中」两档的底色回到普通卡片底 + 主题那两档正文色：原来那底色浅色下与页面底几乎同色，整块看不出是张卡；右上角那颗水印在这两档单独压淡一档。
- 「已激活 / 未激活」两档的取色一个字没动。

### 改：顶栏那几颗圆键按下去会跟着触点轻微偏转

- 手感与首页那张「模块状态」卡同一档（同一支库的倾斜反馈）：按下即倾、抬手回正，点哪边往哪边倒。
- 只加视觉反馈，点击与「禁用时给一句提示」那条路没改。

### 改：命令列表可以多选着删

- 顶栏那颗按钮在这一页变成「编辑」，进去之后每张卡右上角出多选框、右下角那颗变成「删除」。
- 删之前先问一句，窗里报勾了几条；删掉的那几条的绑定一起改成「无操作」。
- 编辑态里按返回是**先退出编辑**（勾着东西时先问一句，窗里动作项叫「退出编辑」），人留在这页；再按一次才离开。

### 改：命令预览换成一扇居中的整屏浮层

- 轻点命令卡、或菜单里那一行「预览」，出来的窗与「捐赠打赏」那张收款码**同一扇、同一段进出场动画**：屏幕居中、缩放淡入，点遮罩或返回收起。
- 单条命令给正文与「以 root 执行」那一行；多条命令给排好的步骤行，间隔带前缀（「执行间隔：3 秒」）。

### 改：命令页顶栏那颗按钮按页签分两档

- 表单那两页是「重置 / 取消」，命令列表那页是「编辑 / 完成」。
- 表单与步骤都空着时置灰，点一下说清没有可清的东西（不干脆不画 —— 顶栏按钮时有时无，大标题宽度会跟着跳）。

### 改：确认窗可以选择强制屏幕居中

- 库在窄屏上默认是从底部滑入，只有内容型窗口（命令预览那种要看一整段文字的）改成强制居中；确认窗维持库的默认档。

### 改：按 ROM 系列分档的适配表

- 内置命令的执行落点与反射面（私有类名 / 方法名 / 字段名）按 ROM 系列收进一张表，一版 ROM 一个条目。
- 本机 ROM 不在表里时照「基准实现」那一档跑，各打一行日志说清现在照哪一档；这条路上不拦、不灰，起不来由执行侧收尾。

### 改：「以 root 执行」的图标换成井号

- 命令设置里那张「以 root 执行」开关的行首、命令列表里以 root 执行的单条命令卡，字形都换成井号（`#`，原来是盾牌 + 代码）：它就是 shell 里 root 的提示符（普通用户是 `$`），比任何「权限 / 防护」的转喻都直接。
- 与「单条命令」那颗终端框仍是两颗字形：一个是提示符、一个是命令框，列表里一眼分得出哪几条会提权。

### 改：系统操作里「音量」「屏幕亮度」两族图标

- 格子放底图本身（喇叭带两道声波 / 太阳），菜单三行放「同一颗底图 + 右下角角标」：加号、减号、齿轮；「音量 + / 音量 −」那两颗按键动作也用同一套，不再按声波数另画。
- 底图不缩小：右下那一笔在画的时候就断开让位，角标落进让出来的空里 —— 一个字形两笔，与图标库里 `bell-plus` / `bell-cog` 的画法一致。
- 缺口按**角标自己**的大小算：角标墨迹（加号看臂长、减号看它更短的那根、齿轮看齿尖）加两格留白成一个圆；音量两道声波都截到这个圆上（原来只截外面那道，右数第二根压根没裁、顶在角标边上），太阳的圆环缺一角，光线碰着这个圆就不画。
- 留白按量出来的来：`bell-plus` / `bell-cog` 里主体墨迹到角标墨迹约 2.05 格，现在切口处也是这个数（之前只有 1.6~1.8）。
- 角标照图标库那几颗画：加号横竖各 6 格、齿轮是一圈加六颗每 60° 的齿（齿比环外伸 1.5 格）。
- 减号比加号短 0.4 格：一条不断的横线看上去总比同样长度的十字长，等长时减号会显大。
- 菜单里的「设置为」不再与格子同一颗（音量、亮度都一样），改为底图带齿轮角标；减号也不做成「喇叭加一条横线」—— 那个形状是通用的「静音」符号，会被读成关掉声音。

### 改：「作者」菜单里酷安那一行换成官方标志

- 原来是九宫格（`apps`）兜底；手绘过三版都不像（官方不是「C 环 + 一个 A」，是一笔连写的 ca）。
- 现在直接取官方矢量：从手机上那版酷安安装包的 adaptive icon 前景层里拿出 pathData（108 视口），等比缩放摆进 24 格、原样填色，形状一个控制点没改。
- 官方这支是实心的，所以只有它填色不描边 —— 上色仍跟别的图标一样由主题给。

### 改：几颗单色图标换成更贴的

- 灵感语音：「三颗闪光」换成 `thinking-low`（侧脸 + 气泡点），与「录音」的麦克风、「唤醒小布」的对话框都分得开。
- 自动亮度：一颗太阳换成 `brightness-auto`（太阳 + 一个 A），与上下两档「亮度本身」不再撞形。
- 手电筒：自绘一颗（宽口灯罩 + 直筒身 + 一个开关记号），替掉图标库里那颗斜放的；动作格与「系统开关 → 手电筒」两处一起换。

### 改：自绘图标收进单独一处，并按职责拆成三个文件

- 手绘的那几支从 `PageIcons` 搬出来：`PageIcons` 只留「名字 → 图标」的查表与按主题选色块那一条判断。
- 拆成三份：`DrawnIcons`（各字形本身）、`DrawnIconCanvas`（画布与笔法、两档色块）、`DrawnIconBadge`（角标与缺口几何）—— 一个 object 里二十个函数会顶到静态检查的「函数过多」，而这三件事的修改理由本来就不同。
- 挪的是位置：字形、调用点行为都不变，色块仍按主题选、侧键那颗仍用于按键卡与组合键筛选。

### 改：清掉命令页与设置页的六处静态告警（行为不变）

- 命令卡那张菜单：四个回调收成一组（参数个数回到上限之下），四行还是「预览 / 测试 / 编辑 / 删除」，每行去处不变。
- 命令页右下那颗按钮：三档去向与字形各自独立成一支，判据与文案一字未动。
- 「删除选中」「退出编辑」两扇确认窗不再收那份用不到的页面状态。
- 「返回上一级」里两段编辑态的收尾各自独立：照样是「先退出编辑态、再按一次才离开这一页」。
- 顺带把菜单自己的 KDoc 从「三行」改成实际的四行。
