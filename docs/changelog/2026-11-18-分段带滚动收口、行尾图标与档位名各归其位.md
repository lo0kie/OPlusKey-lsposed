# 分段带滚动收口、行尾图标与档位名各归其位

## 改

### 改：COUI 抬到 `1.1.0-title2r16`，带子上打了两枚新补丁

- 依赖 pin、`app/gradle.lockfile`、`gradle/verification-metadata.xml`、`patches/coui/build-patched.sh` 的目标版本与 `patches/repo/…/1.1.0-title2r15|16` 的产物一起跟上；
- `0018-tab-row-scrolls-when-labels-overflow`：标签行在最小宽度下仍放不下时整条横向滚动，滑块跟手，判据在库的 `computeSegmentWidths`；
- `0019-tab-row-fits-before-it-scrolls`：每格先收内边距（两侧 12dp → 下限 6dp）再判要不要滚；滑块填充按同一档留白内缩，滚到端头时在留白处收住、不填满圆头。

### 改：带子的左右留白属于视口，不属于滚动内容

- `PAGE_MARGIN` 那一档垫在滚动区外面，滚动区再沿这条内缩后的边界裁一刀，滚到中间时标签不再画到屏幕边上；
- 裁的形状是胶囊而不是矩形：带子两头本来就是整圆，直边裁在圆头旁边会漏出两个角；
- 每格的下限从 52dp 收到 40dp —— 六档两字标签因此装得下、保持静止排布，不进滚动分支；
- 这一层不再替库补第二次 `scrollToItem`：那会与库自己的滚动抢位置，换档时带子先瞬移再被拉回，读起来是抽动。

### 改：行尾的图标与文字各有一个取色出口

- `rowEndIconTint` 收四处（卡片行尾箭头、手风琴 chevron、`RowEndIcon`、`ExpandableRow` 的箭头），降幅走一对默认 1.0 的旋钮，固定色板与 Monet 各一只；要压是乘在它自己那档 alpha 上，不写死 alpha；
- `rowEndTextTint` 给「字」那一档，用次要不透明色、不叠降幅 —— 图标可以更弱，字要读得清；
- 滑杆行的当前值改读 `rowEndTextTint`，与卡片行尾那句同一个色源（原先是另一档）。

### 改：`RowEndSummary` 多一个 `modifier`

- 调用点把这一格再套进别的 `Row` 时由外层限宽（关于页手风琴那行「当前值 + 折叠箭头」就是这么用的），里面这层只管文字与自己那颗图标的先后。

### 改：按键列表与组合列表的标题、副标题不再限行

- 三处 `summaryMaxLines = 1` 撤掉（侧键行、每一颗自定义键行、组合档位行），回到 `CardRow.Item` 的默认上限 3 行；
- 组合行的标题（`ComboTitle` 那段纯文字）也不再限两行，成员多、自定义键名长时整句念得完；
- 只留「挑应用」那一页的限行：那一页的行高是按一行副标题算的。

### 改：「运行状态」那几段各认自己的字形

- 按键响应 `keyboard` → `pointer-pin`（不 ok 那态 `pointer-cancel`）；设置生效 `settings-cancel` → `settings-check`，不 ok 那态另立 `LinkConfigOff`；
- 新增 `LinkConfigUnknown`（`settings-question`）：换包没重启时结论还没定，用「坏了」那颗会读成故障，而用户要做的只是重启；
- 「自定义命令」页顶栏的重置换 `CommandReset`（`backspace`）—— 清的是正在编辑的草稿，与擦掉一整份配置那颗分开。

### 改：字形候选表跟着换

- `FluidIcons` 那张可挑表删掉本轮不再被选的字形、补上新增的六颗（退格、指针带勾 / 减号 / 钉住、设置带勾 / 问号），与 `PageIcons` 同一份。

### 改：「界面振动反馈」补一句前提

- 那行的副标题写「系统静音时不会振动」，开关两态同一句 —— 静音不振是系统那条礼节，与这颗开关开着没有无关。

### 改：版本抬到 1.6.0

- `versionCode` 17 → 18、`versionName` `1.5.0` → `1.6.0`，`ModuleInfo.BUILD_ID` 换成本次出包标记。

## 修

### 修：英文界面下「三击 / 四击 / 单击后长按」掉回中文

- 补五条字典键（`gesture.release` / `gesture.click3` / `gesture.click4` / `gesture.click_then_long` / `gesture.click_then_long_release`，中英两份，`Strings.kt` 走生成器）并让 `gestureLabel` 按 id 认它们 —— 这一支原先只收 `single` / `double` / `long`，其余落到「认不得 = 自定义手势，不翻译」那条 fallback，而 fallback 传的是核心层给日志用的中文常量；
- 仍留在 fallback 上的是第 5 击起（手改配置才到）与将来的自定义手势。

### 修：行尾当前值过长时把那颗图标顶出可视区

- `RowEndSummary` 的文字一格改走 `weight(1f, fill = false)`：`Row` 里不带 `weight` 的子项是按「进来还剩多宽」量的，不是按「兄弟占完之后」量，长值会把后面的图标整个顶出去，连省略号都来不及收。
