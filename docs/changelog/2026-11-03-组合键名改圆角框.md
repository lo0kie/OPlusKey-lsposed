# 组合键名改圆角框

### 改：组合按键列表的两颗键名装进圆角矩形

- 每一颗键名一个圆角框（6dp 圆角，底色与描边跟顶栏那颗图标按钮同一档），`×` 落在两个框之间。
- 框里**只写名字，不套方括号**：框本身就是「这是一个键名」的记号，再套一层括号是重复的装饰；顶栏副标题、删除确认、回执那些「一句话」的场合仍照旧带括号。
- 两个框的宽度各按**整列里最长的那个名字**定，短名字在自己那框里左右补白、字居中 —— 一列下来框一样宽、边缘竖着对齐。
- 名字过长也只在自己那框里省略，不会把另一个挤走。
- `×` 与两个框之间各留 10dp。
- 框里的字做一次光学居中（与「模块 / 系统 / 用户」那几枚小标签同一条通道），上下留白看着才一样宽。

### 修：关掉「命令详情」编辑弹窗后那行字会抽动一下

- 开关弹窗前先摘掉页面的焦点，收键盘引起的那次重排不再把分页器拽动。

### 加：启动自检里检查更新

- 启动自检多一步「检查更新」：查 GitHub / Gitee 两个源（Gitee 暂时与 GitHub 同一个地址，镜像仓库建好只改一处），查到比本机新的版本就弹窗提示。
- 整趟最多等 10 秒，查不到 / 已是最新 / 没网都不打扰，只在真有新版时出声。
- 弹窗带「不再提示这个版本」勾选框：勾了就记住这一版，下次同一版不再弹，出了新版照常提示。
- 「去下载」直接开这条发布的网页；两路的版本号、更新说明、发布页地址用同一份解析。
- 宿主清单里没有网络权限，这一趟请求由注入侧代取：一问一答按编号配对，收不到回包就按「这次没查到」处理（超时 / 广播发不出去各留一行日志）。

### 加：「版本」那一行改成菜单，检查更新收进菜单里

- 「版本」不再直接跳仓库：点一下开一层菜单，里面是「检查更新」与「项目仓库」。
- 点「检查更新」先提示「正在检查更新…」，查完有新版弹窗、已最新 / 没查到各给一句回执。
- 「项目仓库」仍走跳浏览器前的确认窗。

### 改：编辑态下「添加按键 / 添加组合按键」两行禁用而不退场

- 编辑态里这两行不再整行退场，改成**置灰禁用**：编辑态在删、不在加，但行要一直在，用户才知道这一列还能再添。
- 禁用原因那一句：「编辑中不能添加，请先完成」。

### 修：Monet 档整套改走库的权威取色，不再手搓主色族

- Monet 主题下，底子与强调色整套交给库的 `platformDynamicColors` / `ThemeController`（按 MD3 的 HCT tone 映射生成，容器色与前景色是配好对的一组），删掉原来 lerp 朝白推的 `withAccent`。
- 「默认」档直接系统那套原样；「预设色」档按种子重推，并补上系统当前的调色风格与 colorSpec（Android 13 起「壁纸与样式」的调色风格 / 对比度 / 鲜艳度在这一档也生效）。
- 系统强调色的自建三级取色不再参与主取色，只留给配色菜单里「系统取色」那一档的色块。
- 非 Monet 主题（跟随系统 / 浅色 / 深色）仍保持 COUI 固定底子、只换强调色那一族。

### 加：就地状态切换补齐过渡

- 卡片行的标题与副标题改成渐变过去，与同一行的行首图标、行尾箭头同一条曲线。
- 行首字形随状态换的那几处（停用的键换成禁用图标、链接自检结果）改为交叉淡入。
- 行尾那一格在「箭头 / 多选框 / 空」之间换档时交叉淡入：进出编辑态不再整块啪地换掉。
- 多选弹窗里那一行：选中底色、文字色渐变，行尾对勾淡入淡出；那一格恒占位，长名字不再被挤一下。
- 顶栏「编辑 / 完成」那颗按钮的字形交叉淡入，图标色同步渐变。
- 顶栏副标题跟着停用压暗时也走渐变。
- 组合键名那两个圆角框的底色与描边、顶栏圆键的底色与描边、「更多」按钮的字形色、可展开行的行首图标色、输入栏禁用时的压暗，全部改成渐变。

### 修：切「随机图标配色」时图标硬切

- 网格格子、已保存命令卡片、菜单行的行首图标跟着种子一起渐变；卡片行、开关行、滑杆行、可展开行本来就在渐变。
- 三档语义色（禁用灰 / 选中主色 / 危险红）仍优先于随机色，合成同一个目标一起过渡，不出现两条动画各走各的。

### 改：默认配置不许改名与删除

- 配置菜单里的「重命名」「删除配置」在默认配置上直接置灰；核心层的改名 / 删除接口同步拒绝。
- 两颗置灰的行各带一句自己的原因（「默认配置不能改名」/「默认配置不能删除」），点上去出的是这句，不走整页那条默认提示。
- 读不出来的配置槽仍可删（那是腾位置的自救入口），不受这条影响。

### 改：删按键时连带删掉用它配的组合

- 编辑态删掉一颗自定义键，**含有这颗键的组合按键一起删掉**（组合少一颗成员就是废配置，列表里只会画成停用图标）。
- 删除确认窗多一句「其中 N 个含有这些键的组合按键会一起删除」，没有组合受影响时不写这一句；已经勾上的组合不重复计数。
- 回执的「已删除 N 项」把连带删掉的组合算进去；正在编辑的就是被带走的那一组时，编辑目标一起清掉。

### 修：拨开关时滑块硬跳

- 开关行记一份「上一次落定的位置」（页面级、按行记）：行被重建时先摆回旧位置，下一帧再把真值交回去，库的 `Switch` 因此总有一条「旧 → 新」可播；落定 500ms 后把记录更新成新值，不重复播。
- 路由那一段 DSL 与 `PagePagers` 那个包稳住身份（库按 lambda 引用 `remember` entry 表），`LocalIconTint` 改动态档：写配置时不再把整页内容连同正在播的动画一起重挂。
- 顶栏副标题、卡片行标题 / 副标题、组合键名框、选择器行、顶栏圆键等就地状态色的渐变前面已经落地，这一条是那批里唯一还硬跳的一处。

### 加：提示条前面加了一枚图标

- 提示胶囊左侧多一枚与文字同色的前置图标，默认 `alert-circle`（圈里一个感叹号）—— 回执大多是「告诉你一件事」，打勾 / 打叉都会读重。
- 图标不套容器、按一行字的高度画：照库那套 30dp 容器会把胶囊整条撑高。
- 换句时图标与文字一起淡出淡入；同一个位上改字，图标跟着一起换，不留在原地当上一句的记号。
- 接口留了按条指定的口子，目前各处都用默认那一颗。

### 改：「重置配置」与「重置模块」分成两个入口

- 首页 `⋮` 里那一项改叫「重置模块」（连变量表一起清）；只重建当前配置的那一项挪进「更多选项 → 切换配置」菜单，叫「重置配置」。
- 重置配置带确认窗，正文点名是哪一份 —— 只写「重置」很容易被读成「把所有配置都重置了」。
- 两个入口各用一个开关：混用一个时，首页那一项会弹出「重置配置」的话。
- 「重置配置」吃与「重启服务」同一道闸（链路没通 / 这次配置读不出来时灰掉并说明），并按危险色画。

### 改：新建与改名撞名时直接说「这个名字已经有了」

- 新建配置被同名挡下、改名撞上别的配置，都报这一句；原来前者笼统说「新建失败」、后者什么都不说。
- 「新建配置」的满额判定改按**槽位数**算：原先数「有名字的份数」，名字被抹过的那份不算，菜单里于是不灰、点下去才报「最多三份配置」。

### 改：配置在界面上的叫法按身份判，不按「名字空不空」

- 「切换配置」那一行的副标题、删除与重置确认窗的正文，三档分开：默认配置 / 未命名 / 用户起的名字。
- 名字空的普通配置不再自称「默认配置」（用户看到的正是「两份默认配置、我这份动不了」），确认窗里也不再出现一对空书名号。
- 「切换配置」的副标题与那一层菜单取同一份来源，两处不再各拼一遍。

### 改：配置文件多一个 `profile_id`，格式版本升到 20

- 一份配置的身份从「名字空 + 位次 0」换成显式 id：名字被抹空、切换时内容换槽，都不会再让它「变成默认」。
- 老文件读进来时按老口径补一个 id（默认那份拿固定值，其余拿槽位 id），下一次写盘带上；两份撞车时后一份退到槽位 id。
- 导出 / 导入带上这个 id —— 换到别的机器上仍认得出是不是同一份。

### 修：Monet 下弹窗「取消」那颗看不出底色

- 非 Monet 主题仍是 `onSurface` 的 15%；Monet 改用 `secondaryContainer`，字跟着 `onSecondaryContainer` —— 那一档在磨砂面板上差得出来，面板深浅都对得上。
- 危险按钮的字色从写死白色改成 `onError`：Monet 深色档的 `error` 是一档浅红，白字配上去同样看不清。

### 改：命名弹窗的标题行显示字数

- 「新建 / 重命名配置」那颗输入框的字数统计挂到标题行行尾（与「命令详情」编辑窗同一套、同一个位置），上限不再只在输入框里静默截断。

### 改：「选择应用」里名字与第一枚标签之间的间隙

- 名字到第一枚标签的间隙由行通用那一档给，标签之间才补自己那一档；原来每个标签前都补，那一段是两档叠加，读着「标签离名字远了」。

### 改：几处过长的函数与文件拆开

- 「命令」页那三层浮层（全屏编辑 / 详情菜单 / 步骤菜单）单独一个文件，正文那个函数只留「哪一栏画什么」。
- 重置配置那条路把「放开只读位」与「收尾回执」各自拆成小函数。
- `ConfigProfiles` 里三个纯帮手（分配 id / 生成 id / 写盘）挪到文件级，对象只留对外的那几个业务动作。
