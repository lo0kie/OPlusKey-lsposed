# 滑杆拖动刻度、副标题清理与判定器收口

### 滑杆的拖动刻度与取值刻度分开

- `SliderSpec` 多一位 `dragStep`：拖动落点取它的整数倍，取值（手输吸附、写盘、输入窗那句「步进」）仍按 `step`。不传即等于 `step`，既有滑杆手感不变。
- 粗拖不走库的 `steps`：它只能把区间均分，除不尽时会落出 175 / 278 那种数；改由落点吸附取**绝对整数倍**，四格窗口那根于是落在 50 / 100 / 150 …
- 点轨道跳值用同一套落点，点一下与拖一下不再两套节奏。
- 手动输入窗那行常驻说明多报一项**出厂默认值**（`slider.input_range` 从三个占位变四个）。
- 四格窗口那两根滑杆：取值 10ms、拖动 50ms。
- 命令间隔时长那一根：取值 10ms、拖动 50ms。

### 组合窗口与命令间隔的默认值

- 四格窗口出厂值统一 **150ms**（等待整串 / 等待相邻两颗 / 按住整串 / 按住后续成员）；原先前三格 80、第四格 150。
- 命令间隔时长默认 **300ms**（原 400）、上限 **1500ms**（原 3000）；命令库里超过新上限的老值读回时钳到 1500。
- 「按住组合」那张卡里，窗口那两行挪到「首键按住时长」之前 —— 先答「成员多快接上」，再答「凑成的门槛」。

### 一批副标题不再画

- `SwitchRow` 与 `CardRow` 的副标题改成可空（`null` = 只画标题、不留空行），`SliderSpec.summary` 同样可空。
- 关于页、公共设置、命令页、变量页、常用命令、「新建自定义命令」上那一批「解释这个开关做什么」的小字整句去掉，字典里对应的 29 条文案一并删除。
- 「使用预测返回手势」改成「使用预测性返回手势」。

### 场景块的停用标记与行尾菜单收口

- 「已停用」只在整块的小标题上写一次，条件行与动作行不再逐行重复。
- 场景块行尾菜单只剩「停用 / 启用」与「删除」：上移 / 下移删掉，场景块的顺序不再可调（`BranchDraftState.move` 一并删除）。
- 「添加场景（再加一条条件）」的行内入口删掉，只留卡片末尾那一行。

### 「振动反馈」是总闸

- 关掉「振动反馈」时不再有任何振动，包括「按了但没动作」那一支（原先那条 `force` 通道会绕过它）。
- 「无操作时振动」那一颗只在振动反馈开着时出现（公共设置页与独立设置页同一口径）。

### 组合判定器的可选功能与阶段收口

- 三样可选回调（首键补派、按住档固定窗口起点、四格窗口）收成一个 `DetectorBinds`，构造时一次给全；类体里那三个 `@Volatile var` 与装配期的 `apply { }` 删掉。
- 新增 `Combo.phase`（`PAIRED` / `AWAIT_WIDER` / `LONG_FIRED` / `REPEATING`）作为「这一组现在在等什么」的唯一判据，替换四处各写一遍的标志组合。
- 「撤枪 + 清当前组合」收成 `finishCombo` 一支：原先六处各写一遍，漏掉撤枪那一半时定时链会把已收尾的组合再补派一次。

### 新增：判定口径文档

- `docs/runtime/combo-detector.md`：顺序按下、按住档、配对与凑齐、更宽一档的升级、长按阈值、线程模型、阶段、可选功能的装配。
- `ComboDetector` 的类注释只留「与单键判定器的分工」与指针，判据细节以那一页为准。
