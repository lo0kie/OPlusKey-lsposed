# 2026-11-09 · 停用提示不再念错对象，按键列表分卡，首页换成模块名

### 命令抽屉去掉搜索框

- 抽屉里就那几组候选 + 自定义命令，按组扫一遍比先想关键词快；顶上那个过滤框反而挡住「一眼看全」。
- 连带清掉整条搜索链：搜索词状态、命中过滤、只为搜索态挑锚点的那一份、抽屉的三种形态与空提示、两个间距常量、七个只为它用的 import，以及「搜索命令」「没有匹配的命令」两条字典。

### 文案与术语

- `combo.list_title`「组合按键列表」→「**组合按键**」：顶栏本来就是「组合按键」，两处现在同一个词。
- `command.list_title` / `command.tab_list`「命令列表」→「**命令步骤**」：那一块装的是这一步一步做什么。
- `command.saved_commands`「已保存的命令」→「**自定义命令**」：按键绑定页那一节、选择抽屉的标题、那颗 FAB 的无障碍名一起换。
- **「场景」与「条件」分清**：加一整块仍叫「添加场景」，块里加一行改成「**添加条件**」，删一行改成「**删除这条条件**」—— 以前两者都叫「场景」，读不出是在动整块还是动其中一行。
- 代码里的兜底文案、以及把它们当「那个卡片叫什么」的注释一并同步。

### 首页：大标题换成模块名，副标题写模块的作用

- 大标题从「快捷键 / Plus Key」改成模块自己的名字 **OPlusKey**（与 `app_name` 同一串）；宿主 Activity 那串标题退成兜底，只在字典缺这一档时才有机会露出来。
- 副标题**不写版本号**（用户口径）：「把任意动作绑到侧键与自定义按键」。版本只留在「激活状态」那张卡与「更多选项」页。

### 停用的那一份，格子里不再念错对象

- 「组合键」页点格子原来会回落到上一次在按键绑定页看过的那颗键的说法 —— 真机上入口条写着 `[音量+]×[音量-] 已停用`、格子里却是 `[电源] 已停用`。现在先看**这一页在编的那一份**，单键 / 组合两档共用同一句原因。
- 「场景动作」页同理：那一块停用时格子说「这一块场景已停用，回「系统场景」页启用它」，不再借某颗键的名字。

### 按键列表拆成两张卡

- 「按键功能」页原来一张卡装「快捷键 + 自定义按键」，只靠一条加深带分开；改成两张卡、各带小标题：「默认按键」（内置侧键）与「自定义按键」（收集来的键 + 最后一行「添加按键」）。
- 额度那个计数跟着挪到「自定义按键」的小标题上 —— 上限只管收集来的那几颗，挂在内置侧键名下本来就说不通。
- 侧键那一卡只剩一行，新增「自定义按键」卡；原「按键列表」那条小标题随之无人用，连常量带两份字典条目一并删掉。

### 「选择界面」搜索无结果时不再留一条小标题

- 那一节（「Activity」）一条都没有时整节不画，与「快捷方式」同一条规矩：空态只剩空态那一层，不再有一条小标题浮在「没有结果」上面。
- 「这一节画不画」与「搜索时列不列『自动』」收成同一处判据，铺列表与定位用的下标账都读它 —— 两处各写一遍时，要么漏标题、要么定位滚偏一行。

### 系统场景：档位名走字典，并留出自定义手势的口子

- 场景块的动作行原来拼的是枚举里写死的中文，英文界面下会冒出「单击」；改走字典。
- 手势名收成两个口子：认得的 id 走字典、**认不得的原样用传进来的名字** —— 将来自定义手势（用户自己起名）只喂这一个口子，界面侧不用改。
- 「一块有几档」的唯一来源是那份档位表（动作行与手势带都按它排）；接自定义手势要动的就是它，两处都写进了注释。

### 全量审查：配置不再毁掉唯一退路

- 写配置前的 `.prev` 快照只在主文件**读得懂**时才做：以前只排除「读不懂」，于是「正靠 `.prev` 活着」那一档会把坏掉的主文件盖到唯一好副本上。
- 新建配置带上当前这份的自定义键：以前那几颗键会在切过去之后整批消失。
- 导入配置的默认名走字典，不再硬编码中文（那个名字还会写进文件、参与重名比较）。
- 摘要用的规范形态把 `extra_clicks` 也排序：只把两行次数换个位置、内容一字未改，以前会被判成「读不懂」而整页只读。
- 自定义键缺键码时留一行日志再丢弃，不再让「这颗键连同绑定整批消失」无从查起。

### 全量审查：失败不再写成成功

- 按键注入按真实结果返回：被系统拒时上层会走失败回执，以前恒报成功、既没动作也没提示。
- 状态栏指令与截图广播只陈述「请求已发出」，不再断言「已执行」——注入侧没装时那一下根本不会发生。
- 启动更新检查的「本进程已查过」挪到跑完之后：无网或进页即退不再让本进程永久不再查。
- 切配置 / 新建 / 重命名 / 导入覆盖只在完全成功时补一句提示：广播没发出去时注入侧仍是旧配置，以前那句「已切换」会把「注入侧没收到」顶掉。
- 封存资产被拒时按三种签名结论分别记日志：读不到签名不再被说成「包被改过」。
- 版本号任一段不是纯数字就整段作废：`1.3.4beta` 以前被截成 `1.3`，比较结论会反过来。

### 全量审查：宿主页面与界面状态

- 模块页面接线失败时恢复被藏起来的宿主顶栏：以前「保留系统原版页面」留下的是一个没有标题栏、没有返回键的页面。
- 关页后的运行期状态交给 `onDestroy` 收：返回键那条路以前在 `finish()` 之后立刻清，退场动画期间页面拿到的是被清空的那一套。
- 导入配置的读盘与收尾各包一层保护，并在写回前校验页面没换过：协程异常以前会直接崩 `:ui`，换页后结果会被写进旧页。
- 场景分页的页码夹到标签表内：页数从三档缩成两档时，滑块会画到轨道外、库按下标取 tab 还会越界。
- 从「条件 2」那一行挑应用、写失败要重挑时，把条件槽位一起放回：以前会落到别的槽位，覆盖掉同一块里另一条条件。
- 滑杆的步长与上下界加保护：`step` 为 0 或上下界写反只夹到边界，不再崩在组合期。
- 分组日志的异常行带上 cause 链：`InvocationTargetException` 的 message 恒为空，导出日志以前只剩一个类型名。

### 全量审查第二轮：退路、悬空引用与几处判定

- 配置槽与命令库写盘前也留 `.prev` 快照（判据同主配置：当前这份读得懂才留）；命令库加载时被丢掉的条目聚合成一行日志。
- 导入失败的回滚补齐「原本没有这一份」那一档：刚建出来的命令槽要删掉，不能让「报失败」留下半份数据。
- 切配置的空槽回写改成双向：空也是内容，反方向漏写会让目标槽一直带着别人的命令库。
- 语言字典的加载失败受尝试上限约束；`assets/locales` 里没有繁体字典，这一点写进了注释。
- 广播指纹不再拿对象 `toString()` 当值：非标量按「类型名 + 长度 / 有序键」归一，收发两端才比得上。
- 注入侧三处高频上报与自检从 system_server 主线程挪到工作线程；探针取默认网络与真实路径共用同一份实现。
- 后台任务与按键上报的类名收进候选表，Hook 实现里不再就地写类名；取服务单例改走「无参 / 带参」两档，只试一支会在另一种版本上静默落空。
- 双击窗口那一枪改为在锁内读改按压状态；组合键的「UP 丢了」只清那一颗键，并补一条「成员都不在按下表里就重置」的自愈。
- 组合等待的补发与撤销改用同一把锁；配置广播的解析自带兜底，总闸与配置一次替换。
- 文件结果 Hook 按类名集合记忆（宿主有第二种设置页时不再重复挂钩），模块实例没装上时留一行日志。
- 导出日志的收集窗口用 `try/finally` 退出，`Thread.sleep` 被中断不再把接收器留在进程里。
- 页面提醒的「已说过」标记挪到真正弹出之前：这一档被取消时不会再让提醒永久消失。
- 挑应用的三个入口补齐同一套清场纪律，重置会话连「原版动画」那一档一起收。
- 分组键名的列宽把自定义键算进 key：键改名后不再按旧名字截断。
- 分支条件的时间重叠只与**同一块、启用中**的其它条件比：`[18-22 微信]` 与 `[18-22 相机]` 不再互相拦。
- 确认窗标题的固有尺寸四口补齐（私有帮手不再自己换算像素）；正文那一档 gap 只在真有正文时占位。
- 返回拦截里「宿主那层 `onBackPressed`」按类名记账：宿主有第二种设置页时不会漏挂；换页 hook 装不上但生命周期那对装上了，也不再每次进页重复挂一份。
- 导出加了一道「上一次还没收尾」的闸：收集窗口里连点两次不会再拉起两个选择器、把内容写进另一个 uri；导入那条路的说明改成与现在的行为一致（目标由用户挑、可以覆盖当前那份）。
- 「露出宿主原版页」的状态栏底色改成按系统深浅取：浅色系统下宿主主题已被换成浅色变体，再刷纯黑就是「浅色页面 + 黑状态栏」。
- 删掉两个无人引用的函数。

### 协议与判据：外部审查那一批

- 组合键的广播补上**场景表**：只配了系统场景的组合不再被注入侧当成「没绑动作」（以前会出现原生动作与模块动作各来一次）。
- 公共透传位进了广播：关掉之后注入侧按关判，不再一律按默认 `true`。
- 参与组合的键补发时带上**真实按下时刻**，长按阈值不再整体后移一个等待窗口。
- 场景动作页改成**整表写回**：草稿里删过 / 挪过块之后，不再按下标错位丢块或复制块。
- 死分支扫描要求前面那一块**真的会执行**才算盖住，只配「跟随默认」的块不再误拦保存。
- 删命令同时清两份表单（刚删掉的命令不会在另一个 tab 里被「修改」写回库）。
- 切配置改成「附加层任一失败就整趟退回」，导入失败也不再留下半份命令库；变量表的开机复位走同一把跨进程锁；界面状态文件的读改写补同步。
- 反射的方法扫描失败不再把不完整的列表永久缓存；`findClass` 真正落空留一行日志；签名失败缓存改用单调时钟。
- 撤销能真正拦住还没交付的那一枪；组合键「松手才触发」补了抬手丢失兜底；认领窗口与扣留时长的矛盾关系写成判据并在越界时告警。
- 分身清单三档 flags 各自独立尝试；小窗动画事务的所有早退分支都收掉；内置信使超时后晚到的结果丢弃；快捷键复用任务也算成功。
- 状态栏动作的两个实例字段收进同一把锁；Wi-Fi 读不到时条件判不成立而不是当「关」。
- 命令库保存后按新文件指纹播种缓存，主线程不再整份重读；「设置生效」的 blocking 补上宿主开关缺失那一档。
- 检查更新加互斥、偏好与版本号读取挪 IO；命令页按自己那一份表单绑定，过渡期输入不再串页。
- 分身行图标按该用户的 PM 取；新建配置先过只读闸、扫目录挪 IO；跳板提示说清「先去 系统设置 › 快捷键 打开一次宿主设置页」，不再只说「无法打开」。
- 封存资产任务把 keystore 登记为输入；找设备脚本的 `--export` 只输出一行可 `eval` 的赋值。
- 按码点截断、日志按行分片、时间戳补年份；产物校验脚本补跳板三项校验并精确排除目录。
- 「重置配置 / 重置模块」的落盘与整盘删除挪进 IO（`.prev` 快照、原子写、删目录），回执与页面状态仍回主线程；保存配置 / 命令库多了一条同源的 IO 版本，失败不再先写界面状态再回滚。
- 写盘成功后按新文件指纹播种读缓存：下一次写盘不再在主线程整份重读、剥皮、解析。
- 命令步骤的「删除」按身份判「这一格还是我画的那一步」，连点两下不会再删掉后面那一步。
