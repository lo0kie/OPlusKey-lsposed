# 成员连击、顶栏重置与常用命令编辑态

## 改

### 改：按住组合的成员连击（首键按住 + 唯一成员键连击）

- 只在「按住」这一档、且**只有一颗成员键**的组合上出现：首键按住不放，那颗成员键在窗口内
  双击 / 三击 / 四击 / 单击后长按，动作落在**这一档组合自己**那几格，与成员键单键的多击完全解耦；
- 判定复用单键那套连击链：`GestureDetector` 的参数收成 `ClickChainParams` 窄视图，状态机一行没重写，
  窗口与判定时机复用按住组合已有的两份配置，不为它另开一套窗口字段；
- 「按键设置」页多一张「成员连击」开关卡（双击 / 三击 / 四击 / 单击后长按），组合页的手势带上跟着
  多出这几档，动作与开关分两格 —— 关掉只是不判、不派发，配过的动作原样留着；
- 多成员组合与等待组合没有这几档（「哪一颗连击」在那里没有判据）。

### 改：多击链的判定时机默认改为「每次松手重新起算」

- 「固定窗口起点」这一位的出厂值从关改成开（`waitMultiWindow`），连击链与组合窗口共用这一档；
- 老配置里显式存过这一位的照旧按存的值走。

### 改：三页顶栏各加一颗「重置」，范围按页面算

- 「更多选项」只回语言、主题、配色与详细选项；「按键设置」只回本页的接口、振动、提示与单击 /
  组合参数；「独立设置」只回「不再使用独立设置」；
- 三处共用一颗按钮与一张确认窗，整模块重置仍在首页 ⋮ 里，两者不混。

### 改：「常用命令」页加编辑态

- 顶栏「编辑 / 完成」进编辑态：点一行是勾选，右下角滑进「固定 / 取消固定」与「删除」两颗；
  勾选为空时两颗自己滑出，不留点了没反应的按钮；
- 固定按整批判（全都固定着才取消固定），批量删除一次落盘；
- 编辑态里按返回先问一句，没勾选就直接退出 —— 与命令页那一套账同一份。

### 改：加号先问来源，内置命令不再默认写进配置

- 「常用命令」页右下角那颗加号改成先选来源：「内置常用命令」开居中的勾选窗、「手动选择」开原来
  那张动作抽屉；
- 内置那一窗列模块自带的四条（微信扫一扫 / 微信收付款 / 支付宝扫一扫 / 支付宝收付款），默认全勾，
  点「添加」一次落两张表：先按去重规则补命令库（同正文 / 同名跳过），再按 `cmd:名字` 钉进常用
  命令清单，回执报「加了几条 / 跳过几条」；
- 这四条**不再默认补进任何配置**，只有在内置窗里勾选确认才会出现；
- 抽屉里的候选做一次已添加查询：清单里已有的动作灰着、行尾标「已添加」，点一下说一句原因；
  内置窗里同样灰掉、且默认不勾。

### 改：新建配置只带主开关与两个免责确认

- 按键、组合、场景、命令库全回出厂，全局设置也不再整段照搬：只带「模块主开关」与两份免责确认，
  语言 / 配色 / 判定参数都回默认 —— 新建出来是一份「刚装上」的配置。

### 改：按键页「启用 / 停用」改成整批判据

- 勾中的按键与组合**全都开着**才全部停用，否则（含混杂）一律启用 —— 连按两下必定来回翻转，
  不再出现「取反一次还剩一半开着」。

### 改：所有横向分隔线收成两支

- 细线与分组带各一支（`ui/style/Dividers.kt`），卡片行、浮层菜单、选择器、对话框、导入目标、
  命令格式、捐赠名单、首页激活卡这十一处不再各写一遍；
- 浮层菜单里那条不再按亮暗主题单独折算半透明白 / 黑，与卡片里那条是同一条。

### 改：勾选框统一成自绘那一档

- 行尾勾选框用「手绘细圆环 + 实心圆带勾」，与行尾箭头同一格尺寸，进出编辑态行高不跳；
- 多选清单与更新弹窗里那两颗库自带的勾选框一并换过来。

### 改：组合页的手势措辞按主语给

- 组合页的短按一直叫「短按」（不叫「单击」），多成员组合上不再出现那颗并不存在的「单击」；
- 单成员按住组合多出的成员连击几档用本名（与单键那几档是同一件事）。

### 改：「按住多久」滑杆的档位放粗

- 从 10ms 一档改成 50ms 一档（50~500 之间 10 档）—— 这一位只判「按住够不够久」，粗档够用。

### 改：配置版本 78

- `ComboDto` 多了成员连击那一串（动作与开关分格）；老文件没有这一段 ⇒ 全关着 / 无操作，不需要迁移。

## 修

### 修：顶栏按钮之间的空白也会振动

- 振动从槽位容器挪到每颗圆键**自己的边界**上：按在按钮之间的空隙、返回键末端那 8dp 让位上不再振。

### 修：常用命令两条删除路径的正文

- 单条与批量都写明「不会删除源命令」—— 移除只是摘一条快捷方式，命令库与已经绑好的那一处都不动。

### 修：「此版本未实测」那句措辞

- 改成「当前系统版本未经过实测，需要自行尝试」。

## 顺带

- 已知限制里那四条内置命令的说明改成「默认不进任何配置，由内置窗勾选后落库」；
- 静态表生成器的说明同步（四条取自 `CommandSeed` 的候选清单，不再自动种入）。
