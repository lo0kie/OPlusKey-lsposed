# 单击后长按补松手时触发、组合成员连击与顺序组合收口

## 改

### 改：「单击后长按」补上「松手时触发」

- 这一档与长按那一档同一套时序：开着时第 2 击按满时长**不执行**，抬手才执行一次；关着仍是到点即执行；
- 开着它，同一档的「松手执行额外动作」与「连续触发」一并让位（值都留着，关掉就回来），界面那几行跟着压灰；
- 抬手真丢了仍有松手兜底那一枪，只是兜底补的是这一档自己的动作，不再借长按那一档。

### 改：「按键设置」页两张长按卡收成同一套行

- 「单击后长按」那张卡补上「松手时触发」，行序、文案与互斥判据与长按那张卡逐行相同，参数仍是这一档自己的；
- 原先只为这一档存在的那一档分节（只摆后三族、不摆时序）删掉，两张卡不再各有一套行。

### 改：连发那一族改名，按住无动作也不再静默

- 「连续触发时振动」改成「每次触发都振动」、「触发间隔」改成「连续触发间隔」，两行标题直接说清问的是什么；
- 「按了但没动作」那一档的连发重复也跟「每次触发都振动」走 —— 以前按住不放整段完全静默。

### 改：「每次触发都振动」拨开时先拦一道

- 这一档的「振动反馈」没开时弹一句「需先开启振动反馈」，不替用户顺手开总闸（那是这一档所有动作的回执）。

### 改：长按那几张卡的行不再画副标题

- 「松手时触发」「松手执行额外动作」「长按连续触发」「每次触发都振动」「连续触发间隔」「长按延迟」六行的小字去掉；
- 唯一例外是「额外动作」那一行 —— 它的副标题是**取值**（现在配的是哪个动作），不是解释；
- 灰着点一下的原因改走 `disabledHint`，不再拿副标题顶替。

### 改：同位置替换一律不做淡入淡出

- 行尾那一格（箭头 / 自有控件 / 空）、行标题、行首字形、三处顶栏的「编辑 / 完成」都改成原地硬换；
- 颜色过渡照旧，字形与底色同一次到位。

### 改：常用命令的回执说「这一下做了什么」

- 固定 / 取消固定、重命名、换图标、改指向各报各的，不再共用一句「常用命令已保存」；
- 单条固定说「已固定」，两条以上才报个数；行菜单那一项按当前状态写「固定 / 取消固定」，字形跟着换。

### 改：加号里的「手动选择」带行尾字形

- 那一行点开的是底部抽屉（下一层），行尾摆一颗选择器字形；「内置常用命令」不加。

### 改：保存一条跑不了的 shell 命令前先问一句

- 判据是单条命令、两条执行通道都关着、正文是 `shell:` —— 那时它存得下、按下去不会有任何效果，
  而这正是新建命令的默认状态；
- 窗里的动作项是「仍然保存」（存下去不是破坏性动作，不红）；勾了任一条通道就不弹。

### 改：屏状态条件的取值顺序改成亮屏在前

- 选择器里按 `on` → `locked` → `off` 自上而下；三档判据互斥，改的只是读的顺序。

### 改：配置版本 79 / 80

- 79：`KeyDto` 多了 `click_then_long_fire_on_release`；缺键 ⇒ false ⇒ 到点即执行，与这一位出现之前一致。
- 80：`ComboDto` 多了成员「单击后长按」的时序与收尾那一串（`member_click_then_long_fire_on_release` /
  `_repeat*` / `_release*`）；缺键 ⇒ 全关着 / 默认间隔 / 无操作，不需要迁移。

## 修

### 修：按住组合的成员连击判不出「单击后长按」

- 连击窗口原先取的是按住组合那四格（出厂 150ms，量的是两颗**不同**键的按下间隔），第 1 击抬手后
  150ms 内按不下第 2 击 ⇒ 判不出来，窗口到点还先派发一次组合短按；改成单击那一套
  （公共设置的双击窗口 / 判定时机 / 等待窗口）。

### 修：判出成员连击时组合的长按连带执行

- 成员键抬手之后这一组不再是「两颗一起按住」，组合那一枪长按当场撤掉 —— 以前第 2 击按住会让
  组合长按同时到点，一次按压执行两个动作。

### 改：组合页「单击后长按」补齐整套长按设置

- 那一页原先只有动作网格、一个可调项都没有；现在与单键那张卡逐行相同：松手时触发 /
  松手执行额外动作（+ 额外动作）/ 连续触发（+ 每次触发都振动 + 连续触发间隔）/ 长按延迟；
- 这些位是这一档自己的（`ComboKey.memberClickThenLong*`），与组合长按那一套互不影响；
- 松手额外动作的「打开应用」那一路也接上了：挑完写的是这一档的松手格。

### 修：开着成员连击时「首键松手后仍触发长按」不生效

- 成员连击判出一档就把组合收尾了，首键的账没人记，抬手时走到的是「组合已不在」那一支；
  现在这一条收尾也结算它 —— 首键还按着就等抬手补一次自己的长按。

### 改：「首键松手后仍执行长按」改成「首键松手后仍触发长按」

- 这一档做的是把首键自己那一档手势补出来，不是「执行某个动作」；标题按这个说法改。

### 修：组合键「无操作时振动」与「每次触发都振动」同开时只振首次

- 连发跑到「这一档是无操作」那一支时，重复那几下不再被一律跳过 —— 与单键那一支同一条口径，
  按住不放时整段不再是静默的。

### 修：按住组合的「长按连续触发」一次都不响

- 成员连击那一轮在组合长按判出后就收手，连发那串定时链不再被它撤掉 —— 以前按住不放只执行一次长按；
- 连击链那档「单击后长按」一并让位：它与组合长按是同一个按法，一次按压只出一个结果；
- 长按这一档**没有动作**时链照旧全权处理，单击 / 双击 / 三击一直归它。

### 改：按顺序触发的组合只剩单击

- 按住档按顺序触发时不再有「长按」那一页，判定侧也不排长按那一枪（`ComboKey.hasLong` 改成 `!ordered`）；
- 只剩一档时顶栏底下那条手势带整条不画，顺序组合页里于是没有分段控件；场景动作页与分页器页数同源，一起收口。

## 顺带

- 首页「按键列表」、「管理常用命令」、「自定义命令」三处副标题去掉（进去就看得见，标题已经说清）；
- 「触发间隔」的措辞在图标注释、滑杆置灰说明与组合线格式里统一成「连续触发间隔」。
