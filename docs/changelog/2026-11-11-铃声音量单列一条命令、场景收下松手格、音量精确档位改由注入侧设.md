# 2026-11-11 · 铃声音量单列一条命令、场景收下松手格、音量精确档位改由注入侧设

### 铃声音量与媒体音量拆成两条命令

- 新增 `ringervolume:`（`Action.RingerVolume`），与 `volume:` 并列、写 `STREAM_RING`；三档写法与媒体音量同形（`ringervolume:50` / `+10` / `-10`），共用同一组档位与同一张百分比弹窗。
- 为什么拆：来电 / 通知响不响与播放器音量是两件事。ColorOS 自己的小布指令也是两个任务（`MediaVolumeTask` 写 3、`AudioRingProxy` 写 2），连「flags 一律给 0」也照抄。
- 清单多一颗「铃声音量」格（`catalog.ringer_volume`）；`catalog.volume` 的译文改成「媒体音量」/「Media volume」。选中后弹的三行（增加 / 减少 / 设置为）与媒体音量共用文案，靠组标题区分对象。
- 图标：格子是带声波的铃铛，菜单三行是铃铛底图加角标（加 / 减 / 齿轮）—— 与媒体那族的喇叭一眼分得开；步骤行里也是同一套。
- 执行侧与媒体音量同一个实现（`VolumeAction.runRinger`）：铃声流 `0..16`，10% 靠攒零头走成 2、1、2…，十下正好走完。
- 判定侧：`ringervolume:` 不当多条命令（`isSerialCommand` 恒 false）；`ActionTokenTest` 把这一族的标记 token 归进「解析后会被归一」那一份名单。

### 场景块收下自己那一格「松手执行额外动作」

- `SceneRule` 多两位：`releaseOn` / `release`；配置格式 36 → 37，老文件读进来行为逐字不变。
- 组合的场景表（`ComboWire`）一并带上这两项；单键走广播里新加的那一位 `scene_release` —— 注入侧靠它决定抬手发不发 `Release`。
- 「场景动作」页那颗「确认」写回的内容从「三档手势」扩成「动作那几格」（三档 + 松手那一族）。
- 落点：松手这一族在场景块上归**草稿里那一块**（`BindingTarget.releaseSlot` / `bindRelease`），单键与组合仍读自己那份。

### 「场景动作」页只摆松手那一族

- 那一页不再摆「单击延迟」「忽视无操作双击」「长按时序」「连续触发」「长按延迟」—— 这四项的参数归整颗键，注入侧在按下那一刻就按它们排枪，场景条件改不动。
- 留下「松手执行额外动作」：它是这一次按压的收尾，与这一块挑的动作是同一件事的两半。
- 「松手时触发」开在这颗键上时照读并置灰；灰着点一下，提示分页说 —— 场景动作页那句指向「按键绑定」页，因为这一页没有那个开关。
- 「按键设置」那一段的摆放判据收成一条：只有单键那一页摆（组合页、单键的场景块都不摆）。

### 松手额外动作：谁接管这一按，谁自己的开关说了算

- 修「这一档没开额外动作，按下去却冒出来一个」：`pickReleaseAction` 之前只认存下来的动作，两边的开关一个都没看。
- 现在长按被某块接管时以块自己那一格为准（没开 = 这一下什么都不做，不回落按键那一格）；一块都不中才看按键的 `longReleaseOn`；组合键走同一个函数。

### 音量：精确档位改由注入侧设，兜底注入一颗一颗按

- 宿主 `setStreamVolume` 被 ColorOS 静默丢掉（`docs/device/actions/audio.md` 三十四），于是按「谁还能把档位落下去」排级：宿主直写 → 静默重写两次 → 请注入侧（`system_server`）设 → 注入音量键。
- 新增 `ModuleWire.ACTION_SET_VOLUME` 与注入侧 `SystemVolume`：以系统身份 `setStreamVolume(流, 下标, FLAG_SHOW_UI)`，改完照样弹那一路的音量条；宿主读回确认，注入侧未装或版本旧时自动退到下一档。
- 注入按键那一路改成「一颗一颗按、每颗读回」：一颗走几格、还剩多少按实测差值现算；方向在进这条路时定死，越过目标就停（不再反向补）；比一颗键还小的步进一颗都不按，差额带到下一次（欠账上限一颗键）。
- 单次兜底的上限 4 颗 → 16 颗，`volume:0` 这种大跨度也能到位；铃声音量同样走这几档（原来它连兜底都没有）。

### 「场景动作」页挑应用回来写错地方

- 从那一页进「打开应用」挑额外动作时，写回只知道「哪一档组合键」，动作被写进整颗键的 `longRelease`，草稿里那一块一个字节没动，返回后那一行还是「无操作」。
- 这一趟补上「第几块」：场景块写草稿里那一块，单键与组合照旧；「哪一块」与「哪一档组合」一起一次性消费。
- 两条松手写回各补一行 W 级日志（写到哪一档、写成没成）。

### 折行规则收进主题一处声明

- 新增 `appTextStyles()`：以库的 `defaultTextStyles()` 为底，把十四档 `TextStyle` 的 `lineBreak` 统一换成 `LineBreak.Paragraph`，交给页面那唯一一次 `COUITheme(textStyles = …)`。
- 覆盖的是**同一份 `TextStyles`**：不传 `style` 的 `Text`、显式传 `COUITheme.textStyles.xxx` 的、以及库里二十多个读它的组件一起跟着换。
- 命令全屏编辑那一处仍留 `LineBreak.Simple`：命令按短语断会在行尾提前折行。
- 不带 `Hyphens.Auto`：这一页的拉丁字母基本是包名与命令行，自动断字会往这些值里插连字符。
