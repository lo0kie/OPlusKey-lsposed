# 兜底文案全删、静态表生成与滑杆收尾

### 兜底文案全部删掉

- `I18n.get` 收成单参（`operator fun get(key)`）：查不到就返回键名，调用点不再抄一份中文正文。
- 新增 `I18n.getOr(key, fallback)`，只给**动态键**用 —— 键名来自枚举 / 配置、编译器看不见它有没有进字典的那 13 处（导出失败提示、命令失败、作者 / 打赏 / 反馈目标名、常用命令摘要）。
- 静态键的兜底串删干净：115 个文件 867 处，`I18n.get` 之后只剩一个实参。
- `tools/check-i18n-fallbacks.py` 与 CI 里那一步一起撤掉 —— 它维护的就是那份重复文本。
- `docs/process/pre-commit.md` 记一条：兜底不许写回调用点，要一句「字典里没有时说什么」就只有 `getOr` 这一条路。

### 文案键常量改成生成物

- `core/i18n/Strings.kt` 的常量表改由 `tools/gen-static-tables.py` 从 `assets/locales/zh-CN.json` 的键集合生成：那边有一个键，这里就有一条 `const val`。
- 加 / 删一条文案变成单向：改两份字典，跑一次生成器；不再需要「常量与字典两处各删一遍」。
- 已在文件里的常量名原样保留（41 条历史名字与键不同形），新键才按键推导；每条常量上方的注释按段搬运，可以手工补。
- 生成器带 `--check`，CI 加一道「静态表与生成物一致」（重跑生成器再看 `git diff`）。
- `docs/process/pre-commit.md` 新增「静态表」一节：生成物是哪两份、源在哪儿、改完跑什么。

### 「常用命令」那张表搬到 JSON

- 四条内置命令的条目移到 `core/tables/common-commands.json`（`id` / 品牌 / 要不要 root / 字典键 / 兜底文案 / 动作写法 / 一句 `note`），生成成 `present/CommonCommandsTable.kt`；`CommonCommands` 只留读表、念名字与执行。
- 表里的字典键在生成时翻成 `Strings.X` 常量，键写错当场编译失败；动作写法只存后半段，前缀仍走 `Action.*_PREFIX`。
- 那四条为什么这么写（微信起组件、支付宝走深链、哪两条离不开 root）留在 `CommonCommands` 的说明里，`note` 跟着每一项走。

### 长按延迟与连续触发的上限

- 长按延迟上限 2000 → **1000ms**、触发间隔上限 3000 → **1000ms**；滑杆尽头与 `ConfigFields` 的钳制取同一个数。
- 这两根滑杆都改成取值 10ms 一档、拖动落点吸 50 的整数倍（80 / 95 档铺在一根轨道上拖不准，粗拖加手输才是这一行的用法）。

### 等待窗口不再画副标题

- 「单击」卡里那根「等待窗口」与组合两张卡里的窗口滑杆都去掉副标题：管整串还是管相邻两颗，由上面那颗「固定窗口起点」说清，滑杆只回答「等多久」。
- 字典里对应的 5 条文案删掉（818 键）。

### 一批副标题与正文重写

- 「固定窗口起点」「系统场景在首键按下时固定」「首键松手后仍执行长按」「首键按住时长」这几组副标题按「谁按下、等多久、超过会怎样」重写，不再只是换了说法重复标题。
- 长正文在分句处断成两段（`\n\n`）：删除命令、变量占用、按键被组合占用这类弹窗。
- 去口语化（「说一句」「给它」「改不了」这类），术语一律用空格不用方框；英文档同步改。

### 滑杆行首的图标

- 图标往下坐 12dp（`SLIDER_ICON_SINK`）：库只把行首图标居中在「标题 + 摘要」那一块上，`bottomAction` 里的滑杆不算进行高，文本块越矮图标越偏上。
- 走 `Modifier.offset` 而不是 `padding` —— 后者会改量出来的尺寸，父级按新高度重新居中，实际只挪到一半。
