### 自定义命令：步骤行改成通用 selector 行 + 排序态

- **行尾竖三点菜单撤掉**：`StepRowMenuPopup` / `StepRowMenuSpec` 整个退役；只读态行尾改成**与「添加命令」行同一颗**选择器指示（`SelectorGlyph`，两支共用一份），说明「点这一行能换」；
- **新增排序态**（`CommandDraftState.stepEditing`，整页的态：表单与列表都要读）：
  - 「多条命令」页右下角加一颗 FAB（铅笔 / 对勾两档，字形走 `Crossfade`），点一下进出；**只在真有步骤可排时出现**（空表没什么可排的），但排序态里即使把步骤删空也留着 —— 那时工具条是隐藏的，它是唯一出口；显隐交给 `PageCornerFab` 的 `AnimatedVisibility`，别在外面套 `if`；
  - 排序态下行尾换成 **上移 / 下移 / 删除** 三颗行内按钮（首行 ↑、末行 ↓ 置灰，点一下各说一句原因；删除那颗走 `error` 危险色，与浮层菜单 `danger = true` 同一档）；行的轻点不再换命令；
  - 页面其余控件禁用：名称输入（`InputField.enabled`）、命令间隔滑杆（`SliderSpec.enabled`）、「添加命令」行（`BasicComponent.enabled`）、已保存的命令卡（轻点 / 长按 / 测试键）；
  - 底部工具条**整条滑出隐藏**（`commandToolbarVisible` 加 `!stepEditing`），不是置灰 —— 那时改的是顺序不是内容，保存 / 重置都没有意义；
  - 横滑换页在排序态下关掉（`HorizontalPager.userScrollEnabled`），换 tab 由 `CommandTabSync` 摘掉排序态；
- **排序态下的「禁用」一律看得见**（同一档 `DISABLED_ALPHA`，不做两套灰）：
  - 顶栏那条类型选择器带（`CommandKindBand`）整条压暗 + 压一层透明吃事件层 —— 分段控件没有 `enabled` 参数，做法与「按键绑定」页主开关为关时完全一致；
  - 「已保存的命令」卡整张压暗（库的 `Card` 也没有 `enabled`，点击 / 长按 / 测试键同时失效）；
  - 名称输入框整栏压暗（库的 `enabled = false` 只把字换成灰档，观感上仍像能点）；
  - 已保存的命令卡在禁用态**连涟漪都关掉**（`showIndication = enabled`）：这一下本来就不做事，有反馈会让人以为「点了、只是没生效」；
- **提示条那条通道全页共用一个引用**：`LocalHint` / `LocalDisabledClick` 提供的 lambda 一律 `remember` 住（原因若随状态变，用 `rememberUpdatedState` 跟住），否则每次重组换一个新实例，读它的控件会跟着白白重组。改到四处：`PageContent` 的 `LocalHint`、步骤卡「添加命令」行、排序态行内按钮、工具条「保存」那颗（后者抽成 `SaveDisabledHint`）；
- 内容底部留白 `FAB_BOTTOM_CLEARANCE` 从 `BranchScreen` 挪到 `ui/PageFab.kt`，两颗 FAB 共用一份；
- 新增字典键 `command.step_sort` / `command.step_sort_done` / `command.step_sorting_locked`（中英各一条）。

### 切 tab 不再重播步骤动画

- 步骤行的**展示层**（`StepRowItem` + 差分）从 `SerialSteps()` 的 `remember` 搬到页面级状态
  `CommandDraftState.stepRows`（新文件 `ui/state/StepRowDisplay.kt`）：切 tab 时那一页的组合会被
  注销，`remember` 的展示层跟着没了，切回来重新建一遍就是整张表重播进场动画；
- 差分规则原样搬过去（多重集匹配 / 退场锚 / 重建顺序），`exitAll` / `restoreAll` 也一并收进去，
  搬完 `SerialSteps` 里那三个 effect 各剩一行调用；
- 出栈时 `CommandDraftState.discard()` 清空展示层，下一趟进来从干净的一份开始（id 也从头数）。

### 条件执行：加一条挪到 FAB，落盘挪到工具条

- **「添加条件」那颗按钮撤掉**（`AddConditionButton` 整个退役，连同它那两个只服务自己的常量）：
  一页只留一个「加」、一个「存」，两个都在页外，不必猜哪个算数；
- **右下角 FAB 改成「添加」**（`BranchAddFab`，`+` 字形）：加一条空规则，落在表尾并播自己的进场；
  表尾那条还空着时不往下加、就地给一句原因（`addBranchRule` 原样复用）；
- **底部浮动工具条落盘**（`BranchActions`，与「自定义命令」页那条同一份 `FloatingActions`）：
  重置 = 按配置重新载入这一档（没有改动时灰着），确定 = 写回并退页（写盘失败留在原地）；
  灰着被点时由工具条自己说明是哪一档没齐；
- `freshId`（刚加的那一行的身份）从 `BranchCards` 的 `remember` 提到 `BranchDraft`：
  加一条的入口已经在页外，页内局部状态写不到；`NO_FRESH_ROW` 一并搬到 `ui/state`。

### 条件执行：空态在滚动内容里，列表只淡入淡出，表尾注脚零动画

- **空态在滚动内容里**（`BranchEmptyHint`，一屏高 `emptyHeight`）：它得跟着内容一起拖、一起弹 ——
  做成页面浮层虽然省事，但拖动时它一动不动，读起来像「这一页不能拖」；
- **列表**：与空态同属一层 `AnimatedContent`（`sizeTransform = null`），只做交叉淡入淡出
  （`BRANCH_BODY_MS`）；行自己的进出场照旧在 `BranchRow` 里；
- **表尾那句注脚**：零动画，紧跟在行后面 —— 它自己不参与动画就没有「快慢」可言
  （加一条被新行挤下去、删一条跟着收上来）。以前几版都错在给它单独一套 `AnimatedVisibility`：
  那是第二套动画，起跑点 / 时长 / 退出时的重新组合都要和列表对齐，怎么调都差一拍；
- **退出那一支用「最后一次非空」的快照**（`shownRules` / `shownIds`）：删掉最后一条是立即移除，
  而退出中的那一支还要画行与注脚 —— 直接读 `rules` 会让行瞬间消失、注脚弹回顶部；
- **空态时工具条隐藏**（`visible = 规则非空 || 草稿有改动`）—— 后半句不能省：把最后一条删掉
  等于「这一档恢复成无条件」，那一笔也得能存；
- **首次进页不播**：草稿载入之前整块不画（第一帧 `rules` 必为空），载入完成后再画，第一帧就是最终形态。

### 选择应用：空态挪进列表

- 「一条都没有」那块从页面浮层挪进 `LazyColumn` 的一项（`PickerEmptyItem`，`fillParentMaxHeight`）：
  浮层不跟着列表动，拖动时一动不动；进了列表才跟着一起弹；
- 空态那一项存在时**不铺顶上那个占位项**（两者一起才既居中、又不多出一截能拖的空白）；
  `LocateSelected` 按下标滚到当前绑定的行，那时列表必然非空，`APP_LIST_HEADER_ITEMS` 的偏移照样成立；
- 「加载中」那颗转圈仍是页面浮层（它没有「内容」可言，也不需要弹）；
- 顶上那个占位项顺手抽成 `PickerHeaderSpace`，把 `AppPickerList` 压回 detekt 的长度上限。


### 空态收成一支 `Feedback`

- 新增 `ui/Feedback.kt`：一颗字形（32dp 定框）+ 可选一句标题（`body1`）+ 一句说明（`footnote1` 次要色），
  居中、说明左右各留 `PAGE_MARGIN + 16dp`；字形是**插槽**（选择应用那块要放转圈，不是图标）；
- 三处空态统一走它：
  · 「选择应用」那三块（加载中 / 没查到 / 搜不到）—— `PageStatePlaceholder` 只剩「浮在列表上、让出顶栏、
    淡入淡出」，排版交给 `Feedback`；
  · 「条件执行」空表（`BranchEmptyOverlay`）—— 带标题「还没有添加条件」；
  · 「已保存的命令」空网格（`SavedCommandEmptyState`）—— 单行，上下留一档白；
- 三处各自那套字号 / 间距 / 图标尺寸常量（`EMPTY_STATE_TEXT_GAP` / `EMPTY_STATE_TITLE_GAP` /
  `EMPTY_STATE_ICON_SIZE`）退役。
