# 2026-11-09 · 原版动画补分身与组件，场景末尾加行，选择应用页收口

### 打开应用：原版动画在「装了分身的应用」上不再弹分身选择器

- 主用户下启动装了分身的应用：原版动画那条路会先撞上 ColorOS 的「用哪一份」选择器，转场被截断。现在转交之前也挂上跳过选择器的标记，选择器不再出现。
- 挂标记这一支与普通启动那条路共用同一份实现。

### 打开应用：组件目标也能吃到原版动画

- 「应用组件」那一档交给原版链路的那份 intent 补上 `ACTION_MAIN` + `CATEGORY_LAUNCHER`：原版链路靠这一对认「桌面启动」，缺了它只给系统默认动画。
- 只补在副本上：兜底那条路仍用原 intent —— 补了 category 的 intent 拿去起一个没声明它的组件，可能解析失败。

### 打开应用：吃不到原版动画的目标，点确认时把开关拨回关

- 开着「使用原版动画」却挑了分身 / 快捷方式 / 具体界面（这三类拿不到原版动画），点右下角确认会被拦一句；确定即把开关拨回关、按普通方式写下去。
- 这张窗与「不支持以小窗口打开」合成一张：两档只有文案与「拨哪个开关」不同，「说一句、拨回关、照常写」的收尾只有一份。
- 触发点仍是**点确认那一刻**：只有那时才知道这一次要写的是什么，也免得「选中时先弹、用户随后又取消」。

### 系统场景：每一块的场景卡末尾都能加一条条件

- 每块的「场景」卡末尾各加一行「添加场景」，加的是**这一块的一条条件**；与「更多」菜单里那一行是同一个入口。
- 这一块还有没选条件的行时点了只给提示，不插第二条空条件。

### 系统场景：顶栏那颗「添加」不再只看表尾

- 判据从「表尾那块空着」改成「**任何一块**还空着」：空块可能夹在中间（从别处导入的表），原先会再加出一块空的。

### 选择应用：顶栏副标题不再空着

- 没选中时写「没有选择应用」（`app_picker.none_selected`）：这一行始终在 —— 原先空着时顶栏矮一截，翻页 / 返回整页会跟着跳一下。
- 判据改读这一趟的**选中位**，不再只读草稿：结束应用那一趟点一行就是选中（没有二级页、也就没有草稿），原先顶栏还写着上一个应用名。

### 顶栏：除首页外都能折叠，每一页都有副标题

- `canScroll` 只剩**首页**不折（「更多选项」「捐赠列表」原先也钉着标题，那两页字体放大 / 小屏上照样超一屏）。
- 六页补上副标题（原先返回空串，顶栏矮一截、翻页时整页跳）：首页 = 模块版本（`appVersionLabel`）；按键功能 = 「按键列表与组合按键」；更多选项 = 「运行状态、外观与配置」（`more.subtitle`）；捐赠列表 = 「收到的每一份支持都会记在这里」；按键设置 = 「所有按键共用」（`general.subtitle`）；自定义变量 = 「命令与条件里可以引用」（`variables.subtitle`）。
- 另两处兜底：选择界面没有目标时与选择应用同一句「没有选择应用」；组合键编辑页那一组刚被删掉时写「选择按键」而不是空串。

### 只有一个键名时不套方框

- 「条件执行」页副标题的单键从 `[ 快捷键 ]` 改成 `快捷键`（`branchOwnerLabel`）；组合那一档仍是 `[ 侧键 ]×[ 电量 + ]` —— 那里框是为了把两个名字分开。
- 「组合按键列表 - 侧键」同理去框（`comboListTitle`）：` - ` 已经把它与标题分开。

### 键名的显示收成一处（`core/model/KeyNames.kt`）

- 原先同一件事有三份：`ui/model/ComboNames.kt` 的 `keyName` / `comboLabel`、`host/GestureExec.kt` 里抄的一份 `keyName`、以及**各调用点自己决定套不套括号**（`comboLabel(bracketed = …)`）。于是同一个键名在顶栏、回执、执行提示里长出三种长相。
- 现在只有两个出口：`keyName(id)` = 单键**直接写名字**；`comboLabel(cfg, combo)` = 组合 `[侧键]×[电量 +]`（只有一颗时不套框，与单键同一条规则）。`bracketed` 参数与 `ui/model/PageCopy.kt` 的 `keyBrackets()` 一并删掉。
- 落在 `core` 而不是 `ui`：`host` 不许认识 `ui`（`tools/audit-coupling.py`），而执行时那条提示也念键名 —— 要一份实现给两侧共用，只能放中间层。
- 方框与名字之间**不再留空格**：`[侧键]` 而不是 `[ 侧键 ]`。
- 顺带两处对齐：「独立设置」页单键原来直接读 `KeyId.label`（内置键在英文界面下会写成中文的 `侧键`），改走 `keyName`；执行提示里组合那一段原来用 `+` 拼（`侧键 + 电量 +`），改走 `comboLabel`（`[侧键]×[电量 +]`）。

### 捐赠：不备注按匿名标注

- `donate.name_note` 从「不备注按「***」」改成「不备注按匿名标注」—— 表格里那一格仍显示 `***`（数据里不写「匿名」两个字，那是呈现）。

### 绑定页：被「选择应用」盖住再退回来，滚动位置不再归零

- 按键绑定 / 组合键 / 场景动作三页的滚动位置从页内 `remember` 提到页面级，按页各存一份（三页档数不同，不能共用）。
- 离开这三页时清掉，下次进来是新的位置。
- 组合键编辑页离开时一并清掉「挑完回来把抽屉支起来」那笔账 —— 原先只有命令页与系统场景页清。

### 自定义命令：步骤行去掉「第 N 步」

- 步骤行只留整句标题（`打开应用: 微信 - LauncherUI`）、行首图标与行尾那几颗按钮；行次由行的位置自己说，排序态要看的也是行尾那三颗。
- 随之删掉 `common.step_index` 与两份字典条目。

### 文案：指 Activity 的地方不再写「界面」

- 三条既有文案改成 Activity：这个应用没有可从外部打开的 Activity、没有匹配「%s」的 Activity、这个应用没有可启动的 Activity。
- 新增的原版动画那条告知也按这个口径写；指的是页面 / 界面状态的那几条不动。

### 导入 / 导出配置换图标

- 「导出配置」换成 `file-upload`、「导入配置」换成 `file-download`：按「配置交出去 / 文件收进来」摆方向。

### 注释同步

- 「应用控制」那几处注释按现状对齐：网格那一格只用「打开 / 结束」两族的字形、不再按组件 / 快捷方式换字形；抽屉里的额外动作两档都有去路；快捷方式属于「打开应用」那一族，与菜单里那一行的勾同一个判据。

### 文档

- `docs/features/launch-animation.md` 补 10.1：分身目标**没有**原版动画是限制不是缺陷（三条路都堵死）；主用户下启动装了分身的应用**有**动画，前提是挂上跳过选择器的标记。
