# 熄屏单击、抽屉采样、弹窗壳与命令页收口

> 前半段（极暗、音量 / 亮度那一族、定位服务）留在 `2026-10-29-极暗与音量亮度.md`；
> 这里从熄屏那一条起，收的是这一批界面侧改动。

## 一、修：熄屏按下没反应

- 手势窗口的时间基准从 `uptimeMillis()` 换成 `elapsedRealtime()`：前者在深度睡眠里不走，
  熄屏按一下、抬手后设备睡着时，双击窗口那一枪不到点，单击永远不派发；而窗口的截止时刻还停在
  「刚刚」，下一次按下（真实过了几秒）会被判成双击并把前一下的单击吞掉（用户机日志：4.6 秒后那一下
  判成了双击）。
- 熄屏（`PowerManager.isInteractive` 为假）时抬手当场判单击，不再等双击窗口。
  代价：熄屏下连按两下算两次单击，判不出双击。

## 二、修：抽屉里弹出来的菜单采样到了抽屉底下那一页

- 抽屉画在 `COUIPopupHost` 里（页面那层之外），不在页面那份磨砂取样层里 —— 抽屉里再弹菜单，
  菜单采到的还是**抽屉底下那一页**，看着像抽屉被穿透了。
- 现在 `PageSheet` 把抽屉自己也登记进页面那份取样层（`OverlayBottomSheet` 的 `modifier` 上挂
  `hazeSource`）：菜单照旧只采样 `pageHazeState`，糊出来的是「页面 + 抽屉」叠在一起的那一层，
  菜单盖到抽屉外沿时也不会缺一块。

## 三、加：「命令详情」小标题可点，弹出全屏编辑

- 「命令详情」那条小标题改成**可点**（`SectionTitleClick` 那一套，与「已保存的命令」同一条 API）：
  点它弹一个**居中的全屏编辑弹窗**。页面里那个输入框是库的单行 `InputField`，
  带换行或长命令时只能左右蹭着看。排序态下不可点（与整页禁用同一套判据）。
- 可点标题的按压区**右侧收窄**（12dp → 4dp，新增 `SECTION_TITLE_TAP_END`）：左边那 12dp 被
  `offset` 抵消掉、看不见，右边那 12dp 是实打实多出来的空白，按下去状态层铺得太远。
- `SectionTitleClick` 加一档 **`Expand`**（原地撑开一层）：与 `Jump`（跳页）、`Menu`（开合）
  分成三档，语义分开写；字形上 `Expand` 与 `Jump` 都画**同一颗右箭头**（它只表示「点了还有内容」）。
- 弹窗里那根输入框是 COUI 的 `TextField`（`TextFieldMode.Rectangle` + `singleLine = false`）：
  多行、可竖着滚，长度上限与页面那一栏同一档（`MAX_SINGLE_LENGTH`）。
- 字数统计挪到**标题行**（`FrostedDialog` 新增 `titleTrailing` 槽，间隙 `DIALOG_TITLE_TRAILING_GAP`
  = 6dp）：库的 `maxCount` 把计数器画在输入框右下角，贴着框底读起来像另一条信息。
  计数器挪出来之后上限改在这一层截断（超出直接吃掉，光标夹回末尾）。
- 弹窗里那根输入框**不用主题色**：聚焦描边默认是 `primary`，在这一整片编辑区上太抢；
  改成未聚焦 `dividerLine` / 聚焦 `onSurfaceContainerHigh` 的中性色，聚焦与否仍看得出来。
- 弹窗按钮条**恢复全宽**：侧边距只给输入框（库的按钮条是两半平分整个面板宽度，自己带内部边距），
  套在侧边距里会缩进一圈。
- 弹窗编辑的是**草稿的一份拷贝**：取消丢弃、确定才写回；每次打开光标落在末尾，
  粘贴来的 CRLF 在写回那一刻归一成 LF。

## 四、加：「命令列表」菜单里的「测试命令」

- 多条命令那页「命令列表」小标题的菜单多一行**测试命令**（`PageIcons.TestCommand`）：当场把这条命令跑一遍，
  不必回列表页找它。

## 五、加：「命令详情」小标题行尾的菜单

- 单条命令那页「命令详情」小标题行尾多一颗「更多」（与「命令列表」同一套 `MoreButton` + 一层菜单），
  菜单里两行：**全屏编辑**（打开那个多行编辑弹窗）与**测试命令**。
- 标题自己仍可点（开全屏编辑），菜单是给「手就在这一行」的人一个统一入口 —— 「测试」只有菜单里放得下。

## 六、改：所有弹窗的按钮区统一成两颗标准按钮

- `DialogButtonRow` 从「两半平分 + 中间分隔线、贴边无圆角」改成 COUI 的**两颗标准按钮**：
  `TextButton`（取消）+ `Button`（动作项，`buttonColorsPrimary`；破坏性动作用错误色填），
  两颗 `weight(1f)` 平分横向、垂直居中。
- 左右内缩用 `dialogSideMargin()`，按钮边缘与正文 / 输入框对齐；所有弹窗共用这一份（命名、删除、
  放弃、全屏编辑…），全屏编辑弹窗里那份自己摆的行也删了。
- 「灰着但仍可点（点一下说明为什么）」那一档（`onDisabledClick`）改用文本按钮画：填充按钮没有
  「灰着还能点」的形态，硬凑要么看起来能用、要么点不动。

## 七、改：弹窗拆成「头 / 正文 / 底」三区，竖向留白统一

- `FrostedDialog` 改成三段式：**头**（标题上下等边距，天然居中）、**正文**、**底**（新增 `footer`
  槽，按钮在其中垂直居中）。四个间隙全用**同一档** `DIALOG_REGION_GAP`（16dp）：面板上沿→标题、
  标题→正文、正文→按钮、按钮→下沿。
- 竖向留白**只由这一层给**：正文不再自己补上下边距（`DialogBody`、命名弹窗、全屏编辑那几处的
  4 / 8dp 补偿、选择器行组底部的 8dp 都删了），没有 `footer` 时由弹窗补同一档（`dialogBottomMargin` 删掉）。
  这样「有头有正文」「有头有正文有按钮」两种组合的上下留白总量一致。
- 之前那版用了两档（外沿 16 / 区内 12）+ 固定头高 56dp：头里算出来的上边距 15dp 比下边距 16dp 小，
  再叠上正文自己的间距就成了「上边距比下边距少」—— 一档之后不再有这种叠算。
- 按钮区：两颗按钮的间距 8 → **12dp**；`DialogButtonRow` 不再自己补竖向留白与左右内缩
  （交给 `footer` 槽），调用点全部改成 `footer = { … }`。

## 八、改：标题的尾随不再挤走标题

- 以前标题与字数统计在同一个 `Row` 里**整体居中**，统计多宽标题就左偏多少。
- 试过两种极端都不对：`align(CenterEnd)` 居中是对的，但那一格跑到面板右边线上、离标题一整段空白。
- 最终做法是 `CenteredTitle` 这个自定义 `Layout`：标题的测量宽度扣掉 `2 × (尾随宽 + 6dp)`，
  **左右让位相等**（中心不变），再把那一格摆在「标题右缘 + 6dp」。
  `DIALOG_TITLE_TRAILING_GAP` 因此保留。

## 九、改：命令详情随内容变高

- **「命令详情」弹窗不再一开就拉满**：编辑区从固定 200dp 改成 `minLines = 3` / `maxLines = 12`
  （库的 `TextFieldValue` 重载直通 legacy `BasicTextField`，行数一变高度跟着变），
  外面套 `animateContentSize(tween(VISIBILITY_ENTER_MS, EASING_EMPHASIZED_DECEL))` ——
  与页面里其他动态显隐同一档时长与缓动。超过 12 行由框自己竖着滚。

## 十、改：「测试命令」草稿态可点

- 判据从「已保存且没改过」换成「有没有东西可测」（单条写了正文 / 多条至少一步；排序态仍停着），
  灰着那句也跟着换（多条「还没添加步骤」、单条「命令内容还不完整」）。
- 执行侧为此多了一条**直接跑命令对象**的路：`CustomCommandRunner.run(cmd, depth)` 不回库里
  按名字查，`ActionRunner.runTest(cmd)` 走它；`SettingsPage.draftCommand()` 把草稿转成一条
  可执行的 `Command`（名字可以空着，日志里叫「（未命名）」）。原来那条 `runTest(name)`
  与 `command.test_needs_save` 文案一并删掉。
  这样测的就是**屏幕上这份**，而不是库里改之前那一版 —— 按名字跑会测到旧那一版，
  是最容易骗人的「看起来测过了」。

## 十一、修：切 tab 被「拉回」

- **现象**：三个输入框任意一个有值（= 键盘正开着）时切不了 tab，点也回弹、滑也回弹。
- **原因不在分页器，在焦点**：输入框每次重新布局（收键盘、窗口 resize）都会为光标发一次
  `bringIntoView`，而 `Pager` 本身也是滚动容器 —— 它会把「焦点所在那一页」重新滚回视野，
  刚翻过去的那一页就被拽回来。空表单没人聚焦、没有键盘，所以只在「有值」时复现。
- **修法**：换页**先摘焦点**再收键盘 —— `PageTabBand` 的点击回调里 `clearFocus()` 之后才起动画，
  `CommandTabSync` 在页号变化时也先 `clearFocus()`。

## 十三、改：发版前这一批小调整

- 「已保存的命令」卡片的名字降一档（`headline1` 16sp → `body2` 14sp，字重仍 Medium）：
  卡片本身窄，名字跟行标题一样大时两行名字就把格子塞满了。
- 「命令详情」的字数上限 512 → **1024**；编辑区行数上限 8 → **12**（1.5 倍）—— 放宽字数之后
  一次能多看好几行，超出仍由框内滚动，叠上键盘仍在竖屏内。
- 命令详情的编辑区改成**强制换行**：`lineBreak = LineBreak.Simple`，不再沿用平台 `Unspecified`
  （这一版 ROM 按短语断，长命令会因为行尾塞不下最后一个 token 提前折行、右边留一大片）。
- 「自定义变量」的**入口收起**（`ActionCatalog.SHOW_VARIABLES = false`）：按键行为网格里那一格、
  「添加命令」菜单里那一样、首页「其他」卡那一条，三处读同一个常量；变量本身（存储、`setvar:`、
  `${名字}`）一律不动，已用上变量的命令照常跑。
- `shell:` 动作支持**命令自己给提示**：输出里 `tip:` 开头的那一行，成功（退出码 0）时弹成 Toast ——
  「屏幕超时 / 亮度」这类改完屏幕上没反应的开关，靠它回一句「切成了哪一档」。失败不弹（那边已有失败提示）。
