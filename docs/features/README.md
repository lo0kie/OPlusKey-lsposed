# 专题

一个专题一个文件（或一个目录），里面是「把这件事做完」需要的全部材料 —— 结论、配方、踩过的死路。

| 文件 | 收什么 |
| --- | --- |
| `launch-animation.md` | 侧键「打开应用」的转场动画：调用链、常量、曲线、几何、逐帧模型、COE 扫光、门禁分析、复刻边界 |
| `zoom-window/` | ColorOS 小窗：实现笔记、接口取证、补充取证，见该目录的 `README.md` |

`launch-animation.md` 是完整技术文档；`device/actions/launch.md` 的四十七节是它的摘要与结论，
两者冲突时以 `launch-animation.md` 为准。
