## 1.4.1

### 新增

- **录音一格三档**：切换 / 开始 / 结束。老绑定仍是「切换」；「结束」只停，不在录音时什么都不做。
- **「打开应用」可套原版启动转场**（`选择应用` 页 ⋮）：直接转交回 ColorOS 自己那条链路，不是复刻。
- **系统场景改成「一块 = 单击 / 双击 / 长按三档」**，每块末尾都能加条件，多一条「手电筒」条件。配置自动迁移，升级前后行为不变。
- **场景里点一行动作进的是「按键绑定」那张网格**（同一份界面、同一套手势带），右下角确认才写回这一块。
- **组合键最多三颗**；「按键之间的等待」可以每组单独设（上限 300ms → 1000ms）。

### 改进

- **顶栏副标题挪到大标题下面**，不再把标题挤成省略号；除首页外每页都能折叠、都有副标题。
- **首页大标题换成模块名**，副标题写模块的作用，版本号不再挂在副标题上。
- **「按键功能」页拆成「默认按键」与「自定义按键」两张卡**，额度挂在后者。
- **选应用 / 选组件都改成「读全了再显示」**：进页先转圈，清单一次铺出来。选应用还让有启动图标的那批先上屏，其余在后台接着算。
- **独立设置显示的是生效值**（跟随公共时显示公共那份），只在你第一次打开时抄一次公共值，之后改一项只写那一项。
- **文案与术语收口**：组合按键 / 命令步骤 / 自定义命令；「场景」与「条件」分层；指 Activity 的地方不再写「界面」。
- **命令抽屉去掉搜索框**；自定义命令的步骤行去掉「第 N 步」。
- **配置能自愈**：主文件写坏自动用上一版恢复，页面照常可写。「重置模块」把模块落过的盘全部回出厂。

### 修复

- 修复**桌面上钉住的快捷方式列不出来** —— 改由系统侧读快捷方式服务的活数据。
- 修复**组合键抢跑**：小的那一档不再抢在大的那一档前面派发。
- 修复**命令正文多行粘贴后框里看不见字**；两个 tab 的表单不再互相清空。
- 修复一批**失败被写成成功**：按键注入被拒却报成功、状态栏与截图断言「已执行」、更新检查在无网时永久不再查。
- 修复一批**数据被盖或页面崩掉**的路径：配置版本没跟着抬、导入覆盖把读不懂的原库永久盖掉、新建配置丢掉自定义键、两条命令重名、多条命令切进编辑态。
- 修复**设置写了却不生效**：按键独立设置与三档同事件的字段只写了一半点。

### 移除

- **撤掉「开机提前拉起宿主服务」**：它每次开机都会自己弹一次模块页。取舍是回到「开机后约 15 秒内侧键动作不执行」。

### 下载

- `-release` 是正式包，管理器更新到的就是它。
- `-releaseLog` 与正式包完全相同，只是打开了详细日志，排查问题时用。
- `-debug` 是调试包，只用于复现。
