## 1.3.4

### 新增

- **屏幕亮度与音量**：「系统操作」里多了两格，各三档 —— 增加 / 减少 / 设置为，选好百分比再确认。亮度动作会让控制中心的亮度条当场跟过去；自动亮度开着时这一档需要 root。
- **检查更新**：打开设置页自动查一次（GitHub 与 Gitee 两路并行，最多等 10 秒），有新版才出声；「版本」那一行改成一层菜单（检查更新 / 项目仓库）。更新说明按 Markdown 显示，长了在框内滚动。
- **首页更新提示**：查到新版后首页顶部会出现一条提示，右侧「查看」打开说明；同一条信息不再在别处重复出现。
- **按键功能编辑态**：顶栏「编辑 / 完成」，两张清单都能勾，勾中后右下角滑出「删除」；编辑态下按返回是退出编辑，不会把你带回上一页。
- **浮层菜单滚动条**：菜单装不下时右侧常显一条，滑到两端不压圆角，按住时有触觉反馈。

### 改进

- **改名与入口**：「组合按键」→「按键功能」，「通用设置」→「模块设置」；「添加按键」搬到按键页末行。
- **组合按键列表**：键名装进圆角框、两列竖着对齐，长名字不再被省略号截断；键名的括注改成半角方括号。
- **配色**：Monet 档整套交给系统色板（底子与强调色一起跟随），修好 Monet 下滑杆刻度点看不见的问题。
- **一致的手感**：顶栏按钮、卡片行、「选择应用」与「选择界面」两页的行都用同一份行高与按压反馈；弹窗里的滑杆、开关、滚动条统一走系统触觉反馈。
- **其他**：「灵感语音」只在长按档出现；卡片行的状态切换带过渡，不再突跳。

### 下载

- `-release` 是正式包，管理器更新到的就是它。
- `-releaseLog` 与正式包完全相同，只是打开了详细日志，排查问题时用。
- `-debug` 是调试包，只用于复现。
