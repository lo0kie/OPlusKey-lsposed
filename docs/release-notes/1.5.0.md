### 新增

- **「按住组合」**：先按住首键、再按另一颗即可触发；首键的长按动作须为「松手时触发」，未设置时会先询问并一次写入，后续成员不限颗数。
- **「只参与非首键的按住组合」**：这颗键不作按住组合的首键时，单击与双击完全交还系统；作为后续成员时照常生效。
- **内置动作「计时器」**：在快捷功能中直接选择时长（30 秒至 2 小时），状态栏开始倒数，不打开时钟界面。
- **执行提示支持流体云**：使用 ColorOS 接口时默认以状态栏胶囊提示，也可改为 Toast。
- **提示模板的变量增加到六个**：在键名、手势、动作之外新增父级名称、命令名与系统状态三项；提示文案弹窗中列出全部变量，点击即可插入。
- **自定义命令新增三种写法**：`toast:`、`notify:` 与 `fluid:`，分别弹出轻提示、发送通知、弹出一颗流体云胶囊；流体云可指定图标。
- **自定义命令支持系统状态变量**：电量、蓝牙、Wi-Fi、响铃模式等系统状态可写入命令正文。
- **双击归入多击手势并独立开关**：与三击、四击一致可单独关闭，关闭后不再为双击延长单击等待。
- **多击判定可选两种时机**：逐次等满（每次松手重新起算）或只等一个窗口（自首击起算），等待窗口可单独设置。
- **「常用命令」页**：任意动作可收进一张清单，支持改名、更换图标，并逐条决定是否显示在按键绑定页。
- **「无操作时振动」**：按下有反应但该档未配置动作时给出触觉反馈，公共设置与每档独立设置各一项。
- **「首键松手后仍执行长按」**：按住组合触发之后，首键抬起时再执行它自己的长按动作；默认关闭，开启后一次按压会执行组合与首键长按两个动作。
- **「界面振动反馈」开关**：模块页面内的点按、开关与滑杆触觉可单独关闭，位于「更多选项 → 外观」。

### 改进

- **组合按键的触发方式简化为一档一种**：每档只认「等窗口」或「按住」之一，列表按等待组合与按住组合分两列，同一组键可有多档。
- **单击相关参数拆成全局默认与逐键两份**：未开启独立设置的按键统一按全局一份判定；判定时机、等待窗口与单击延迟集中在独立设置页。
- **常用命令的显示与移除独立**：移除一条只从清单中摘除，已绑定的按键保持原样；每条可单独更换图标。
- **命令详情只接受支持的命令格式中的六种前缀**：写法不符时直接说明；输入框下方按当前前缀给出该写法的格式提示。
- **命令、常用命令与变量设上限**：达到上限时说明原因。
- **图标选择器覆盖模块使用的全部字形**：新增动作的行首图标一并可选。
- **设置页的参数卡由公共设置页与独立设置页共用一份**：独立设置页按手势只摆相关的卡 —— 单键只摆单击，组合只摆它自己那一种触发方式。
- **组合参数按触发方式分两张卡**：「按键之间的等待」归「等待组合」；「首键按住时长」「系统场景在首键按下时固定」「首键松手后仍执行长按」归「按住组合」，不再混在同一张卡里。
- **多击档留空就是什么都不做**：双击 / 三击 / 四击那一档没有配置动作时，不再退回执行单击；原先那条「无操作时执行按键命令」随之退场，留空即无操作。
- **组合键使用的系统场景改在首键按下那一刻确定**：想要的系统状态在按住之前就锁定，按住途中切了应用也不会换一套动作；仍可在组合参数里改成凑成时取（默认首键按下）。
- **删除按键前先检查组合**：这颗键还用在某几档组合里时会拦下并点名是哪几档，不再出现删完之后组合指向一颗不存在的键。
- **页面图标统一一批**：系统场景固定、按键之间的等待、首键按住时长、首键松手后仍执行长按各用一颗语义相符的字形。
- **按键判定的固定开销降低**：配置读取的指纹不再每颗键各算一次，热路径日志在正式包里不再生成字符串。
- **滚动条统一**：浮层菜单、选择应用、图标选择器、更新弹窗与抽屉一致，拖动时有触觉反馈。
- **键盘收起后输入框自动失焦**。
- **导出的日志带文件头**：机型与系统版本、各进程版本与日志状态、配置摘要。
- **首页菜单两行增加副标题**：宿主进程运行时长与日志缓冲行数。
- **「选择应用」多选的行尾改为序号**：已选数量一目了然。
- **界面用语统一**：「按键功能」改为「按键列表」，「接口选择」改为「接口与显示」，「只参与组合」改为「只参与非首键的按住组合」；英文文案同步。

### 修复

- **电源键与音量键都被接管后，同时按下仍触发系统截图**。
- **「重启服务」后设置页消失**：需重新进入模块才能打开。
- **上一条动作执行较慢时，下一次按压同时触发两套动作**。
- **「选择应用」页首次进入停在第一行**：与当前绑定不一致。
- **使用原版动画打开部分应用时没有动画**：部分机型上还会连带让宿主进程出错，表现为「先是没动画，接着所有按键都没反应」。
- **手电筒与免打扰的提示中缺少状态词**。
- **停用的场景块仍使「松手执行额外动作」成立**。
- **导入超限的命令库后所有保存失败**。
- **非当前配置损坏一次后无法再使用**。
- **通知渠道被删除后提示不再显示**。
- **录音相关动作在事务线程挂起后整进程失效**。
- **关闭双击后快速点两下没有任何动作**：只给出一次触觉反馈；现在各算一次单击。
- **界面细节**：菜单行禁用时副标题未压暗、卡片首行隐藏后第二行顶部多出一条细线、顺序选择器条目重复且带选中样式。

### 下载

- `-releaseLog`：与正式包一致，仅开启详细日志，用于问题排查。
- `-debug`：调试包，仅用于问题复现。
