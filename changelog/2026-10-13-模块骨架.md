# 2026-10-13 · 模块骨架

### 接管面

- 注入 system_server，按 `StrategyActionButtonKeyLaunchApp` → `PhoneWindowManagerExtImpl` → AOSP `PhoneWindowManager` 的顺序降级挂点
- 全程按类名字符串反射解析，不直接引用任何 `com.android.server.*` 类型
- 只认侧键：电源键与音量键一律放行

### 手势与动作

- 单击 / 双击 / 长按三档在注入侧判定，长按支持连续触发
- 动作由 `config/Action` 统一解析：打开应用、自定义命令（Shell）、手电筒、响铃模式、按键注入
- 判定在 system_server、执行在宿主进程，两者经广播转交

### 配置与界面

- 界面寄生在宿主「设置 → 快捷键」页内，Compose + COUI 渲染
- 配置写宿主私有目录，只有宿主进程读；注入侧只经广播接收
- 模块零入口 Activity，LSPosed 管理器不显示「打开模块」

### 构建与发布

- AGP 9 内置 Kotlin，JVM 21，compileSdk 37
- debug 与 release 共用正式签名
- GitHub Actions 出 debug / release 包，release 发往 `Xposed-Modules-Repo/io.github.lo0kie.opluskey`，tag 为 `<versionCode>-<versionName>`
