# 亮度音量动作与更新窗红点

### 加：「系统操作」里的「屏幕亮度」与「音量」

- 两格入口各三档：增加 / 减少 / 设置为；三行都是入口，点开再弹一个百分比（菜单里那三行是 `bright:+` 这样的占位写法，不落盘），确认才落 `bright:+15` / `volume:50` 这种带数值的写法。
- 百分比弹窗两族共用一根滑杆：按 5% 吸附、点轨道直接跳值、跨档振一次；「设置为」可以从 0 起，「增加 / 减少」从 5% 起（增加 0% 不是动作）。
- 网格格子的小字写「增加 15%」这种带数值的说法，与步骤标题、执行提示同一句口径。
- 执行：亮度按「控制中心的量程」折算百分比并夹紧两端；音量只碰媒体流、按整条量程折算，写入带 `FLAG_SHOW_UI`（与按物理音量键同一个反馈）。

### 加：亮度动作让控制中心的亮度条实时跟随

- 执行顺序照小布：先由注入侧在 system_server 里调 DisplayManager 的临时亮度把背光推到目标值（那根条只在「背光真的变了」时才刷新），再写 `screen_brightness`；自动亮度开着时用 root 补写 `screen_auto_brightness_adj`。
- 写完再补一次 `screen_brightness_duration`：ColorOS 在自动亮度下会丢弃 `screen_brightness` 的变更通知，不补这一下条还是停在旧值（关掉重开才对）。
- 自动亮度开着那一档依赖 root（每次一次 `su`）；手动亮度不 root、不用 shell。

### 加：更新说明按 Markdown 渲染

- 弹窗里的更新说明按 GFM 解析：标题、列表、加粗 / 斜体 / 删除线、行内代码、链接、引用、代码块；解析失败退回原文。
- 行内代码底色用比弹窗底深一档的颜色（主题的 `surfaceContainerHigh`），两侧各垫一个薄空格当内边距。
- 正文区限高约十行，超出滚动，右侧一条常显的 COUI 滚动条；滚动条贴近弹窗右边，正文左右缩进与标题对齐。
- 引入 `org.jetbrains:markdown`，同步依赖校验和与锁文件。

### 加：有新版本时的红点

- 红点只出现在首页那条提示的前置图标上，颜色用主题的错误色（跟随 Monet 换色），不用 COUI 内置那两颗固定红。
- 「更多选项」「版本」两行与「版本」菜单那一行不再挂点。
- 调试包可以用 `settings put global opluskey_mock_update '<release JSON>'` 假装有一个新版本（正式包不认这个键）。

### 加：首页顶部的更新提示条

- 查到新版后首页第一块之前钉一条提示条：下载图标带红点、正文写「发现新版本 1.3.4」、右侧一颗「查看」。
- 点「查看」弹出的是那个「发现新版本」窗（与「更多选项 → 版本」里那个同一个：说明、稍后、不再提示都在），不在提示条上直接跳浏览器；点完这一条不消失。
- 这条跟红点同一件事、同一份状态：按「稍后」留着，在窗里点「去下载」或勾「不再提示」才收。
- 提示条按 COUI 那条的颜色、圆角与字号自绘：库不暴露内容的纵向位移，文字比条带中心高一档补不回来（图标、文字、「查看」现在落在同一条中线上）。
- 首页「更多选项」、「版本」两行与「版本」菜单那一行**不再挂红点**：有新版由这条提示说，同一条信息在一页里只出现一处。
- 勾过「不再提示」只压自动那一趟（进页面时不弹、不点亮提示）；自己点「检查更新」照样弹窗，只是不上首页提示，窗里也不再给「不再提示」那一行（同一版不重复问）。

### 改：几处参数表与判据日志的写法

- 「亮度 / 音量」百分比弹窗的三个同源参数（标题 / 最小值 / 百分比怎么念）收成 `PercentPrompt`，调用点仍是那两处。
- 百分比拆分与亮度 / 音量那两支解析挪到 `Action` 文件级；`ActionCatalog.isBound` 里两族的占位写法判定抽成一处。
- 组合键标题的判据日志改为在调用点拼好一行、只剩一个去重出口。
- 调试用的假更新读口挪出 `UpdateState`（对象函数数贴着上限），行为不变。

### 改：「检查更新」在有新版时的说法

- 「版本」菜单里那一行改口「发现新版本」、图标换成下载；不再带行尾红点。

### 改：弹窗里库控件的振动转投通用通道

- 弹窗面板挂上与浮层菜单同一层的转投：滑杆、开关这些库控件自己发的振动改走页面那条通用振动（跟着系统静音走），不再直接漏出来。
- 「不再提示」整行点击补上那一下。

### 改：「灵感语音」只在长按档给出

- 条件页的步骤菜单按当前规则的手势档过滤：短按规则的菜单里不再列出它。

### 改：组合按键列表键名两列的排版

- 第一列最少占整行 45%，键名框字号缩到 0.85 倍并在量宽之外补 2dp 余量，较长的键名不再变省略号。
- 量宽度与画字用同一个比例，fits 不会再判错。

### 改：检查更新两路各打各的接口

- GitHub 那一路问模块仓库、Gitee 那一路问源码仓的 Release；两路**并行**发起，都回来之后按版本取较新的那条，不再「谁先回来算谁」。
- Gitee 的 release 对象没有 `html_url`，地址由这一路按 tag 拼，「去下载」照旧打得开。
- 钉版那条流程末尾同步一份到 Gitee 的 Release：没配令牌就跳过、只留一条 notice；配了却传不上去算这一条 run 失败。

### 改：「已知限制」补上自动亮度那一档

- README 的「已知限制」写明：自动亮度开着时「屏幕亮度」动作每次执行要用一次 `su`；手动亮度不用 root、不走 shell。
