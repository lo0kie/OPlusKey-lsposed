# 浮层滚动条与系统配色取色

### 加：浮层菜单能滚动时右侧常显一条滚动条

- 菜单内容超过面板上限时，面板右侧出现一条 COUI 滚动条；装得下的时候不出现。
- 这条滚动条**常显**：不去碰它也不淡出。
- 滚动条上下各让出 8dp，滑到两端时不压在面板圆角上。

### 修：Monet 底子也跟随「强调色」那一行

- 选了强调色之后，Monet 底子的主色 / 主色容器 / 禁用主色都按强调色来，不再用底子自己算出来的那一套。
- 系统强调色取不到时依次退到宿主主题主色、常量蓝，不再静默落回蓝。
- 取到哪一档、色值是多少，打一行「页面配色：主题=… 强调色=… 深色=… 主色=…」的 W 日志。

### 改：补丁产物与依赖校验和

- 重打 `coui-ui-android` 补丁包：列表弹层可传入自己的滚动状态，滚动条新增「常显」一档。
- 同步 `gradle/verification-metadata.xml` 里那份 `.module` 与 `.aar` 的 sha256。

### 改：「按钮绑定」页的系统场景那一行始终显示

- 这一档一条场景都没有时那一行也留着，写「当前手势没有添加系统场景」—— 它同时是进「系统场景」的入口。
- 有场景时仍是「当前手势有 N 个系统场景判断」（只数启用中的），点一行进对应手势。
- 「组合键」编辑页的短按 / 长按两档同一口径。

### 改：「选择应用」与「选择界面」两页的行改用通用的一行卡

- 两页的行改用 `CardRow.Item` + `CardList`：行高、行距、按压反馈、点击振动、行首 / 行尾两个槽位与设置页其余行同一份定义。
- 行首的应用图标与新加的「分身 / 模块 / 系统 / 用户 / 不可打开」标签分别走新增的 `startIcon` 与 `titleExtra` 两个槽位。
- 「选择界面」页那声点击振动随通用行自己走，调用点的 `tick` 参数撤掉。

### 改：键名外面那对括号换成半角方括号

- `[侧键] × [电量 +]`：中英同一对半角方括号，不再用 `「」` / `｢｣`。
- 仍然只有 `keyBrackets()` 一处口径，列表行、筛选标题、顶栏副标题、表尾注脚、回执一次全换。

### 改：组合按键列表的标题改两列

- 一行里的两颗键名分成两列画，中间一个 `×`；两列宽度各取整列最长的那个名字，一列下来竖着对齐。
- `×` 摆在那一段空的正中间，两个键名到它的距离相等。
- 分隔符用 `×` 不用 `+`：键名自己就可能带加号。

### 加：「按键功能」页的编辑态（勾选 → 删除）

- 顶栏那颗「设置」改成「编辑」，进编辑态后换成「完成」，再按一下退出（选中一起清掉）。
- 编辑态里**按键与组合按键两张清单都能勾**：行尾换成多选框，点一行是勾选而不是进绑定页 / 编辑页；内置侧键那行置灰并说明「内置侧键不能删除」，「添加按键」「添加组合按键」两行退场。
- 勾中任意一项，右下角滑入「删除」；一项都没勾时它滑出。
- 删除前先问一句（「删除选中的 N 项？」），一次落盘：按键连同它自己的设置一起删，组合整组连动作一起删；引用了被删键的组合保留成「成员缺失」那一档，不级联删别人的配置。
- 编辑态里按**返回**先问「退出编辑？」，问完才真的退页；没有勾选时直接退页。
- 编辑态里按返回不再让预测手势停在半路。
- 整页闸门关着（总闸关 / 链路没通 / 配置只读）时，那颗「编辑」置灰并说明原因。

### 加：跳浏览器前先确认

- 「版本」「作者」「反馈」那几处外链，点下去先弹一句「打开网页？」（正文是目标地址），确认后才跳出去。

### 改：网格的列数按可用宽度算

- 「按键行为」与「已保存的命令」两片网格按可用宽度排：每格不小于 150dp，窄到放不下两列时排一列，宽了就多排。
- 两处共用同一个算式（`gridColumnCount`），算列数与按行分块用的是同一个数。

### 改：顶栏图标按钮收成一份

- 各页顶栏右上角那几颗（添加 / 重置 / 编辑）改用同一个 `HeaderIconButton`，位置与尺寸一处定义。

### 改：顶栏底下那条分段带跟随主题配色

- 带子的底色、选中底色与文字色按主题（含 Monet 与深色）给，不再用库默认那一套。
