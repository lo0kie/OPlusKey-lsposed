# 「添加按键」搬进按键页、首页那行改名

### 改：「添加按键」从首页搬进「按键」页

- 收集一颗新键的入口挪到「按键列表」的**末行**（用户口径）：它做的就是「往这张清单里加一行」，与清单同一张卡才读得通；摆在首页那张卡上时，它与上面那行入口是两件不相干的事。
- 满员时那一行的副标题与「为什么点不动」照旧（`KEY_WATCH_LIMIT`），整页闸门关着时仍交给整页那条。
- 首页那张卡随之只剩一行，`HomeUiState` 里那个收集窗的置位也一并撤掉（收集窗改由「按键」页自己持）。

### 改：首页「组合按键」改名「按键功能」

- 那一行现在指向的是**整页按键功能**（按键列表 + 添加按键 + 组合按键列表），不再只是组合那一列，所以名字跟着改。
- 也因此**不再按「有没有自定义键」置灰**：一颗自定义键都没收时那一页照样有用（侧键在里面、添加按键也在里面），灰掉等于把入口关了。
- 副标题两档：一组组合都没配时说这一页有什么，配了就说已配几组。
- 文案键换成 `keys.entry` / `keys.entry_desc`（`combo.entry`、`combo.need_key` 随之撤掉）。

### 改：首页那一行只留一句说明，图标换成一根手指

- 去掉「已添加 N 组」那一档副标题：那是**统计**而不是入口的说明，配了几组进去就看得见，首页不必报数。剩下的那一句始终是「按键列表与组合按键」，行高也就不会再随组合数变。
- 图标从两只手指（`hand-two-fingers`，说的是「两颗键一起按」）换成一根手指（`hand-finger`）：这一行现在指的是按键本身。

### 改：「通用设置」改名「模块设置」

- 顶栏标题与首页那一行共用同一个键，两边一起改；英文档 `General` → `Module settings`。
- 注释里提到那一页的地方跟着改口径（`Screen` / `PageEntry` / `PageIcons` / `HomeCards` / `HomeScreen` / `Strings`）。

### 改：「按键功能」页的顶栏标题跟着改名

- 那一页的标题从「按键」改成「按键功能」，与首页点进来的那一行同名（`keys.title`，英文 `Key features`）；注释里提到那一页的地方一并改口径。

### 改：「组合按键设置」搬到「模块设置」

- 那一节（无操作时执行按键命令 / 按键之间的等待）从「按键功能」页搬到「模块设置」页尾：两项都是**全局**的，与「有哪几颗键、配了哪几组」无关，与那一页另外两节同一类。
- 卡片与滑杆那一支跟着搬（`GeneralComboCard.kt`），「按键功能」页只剩按键列表与组合按键列表两张清单。

### 加：「按键功能」页顶栏那颗「设置」

- 右上角一颗齿轮，直接进「模块设置」—— 组合按键那两项搬走之后，改它们不必先退回首页再点「其他 → 模块设置」。
- 走 `navTo`：从「模块设置」退回来仍是按键功能，不是直接回首页。

### 修：Monet 配色下滑杆的刻度点看不见

- 那个圆点原来取「轨道那一色 × 4 倍不透明度」—— 这条路只在库自带色板下成立（那边 `sliderBackground` 是 5% / 10% 的前景色）；Monet 那一档整套配色是库按系统配色另算的，`sliderBackground` 在那里是不透明实色，乘几倍还是同一个颜色，点与轨道一模一样。
- 改成取**前景色**（`onSurface`）按固定不透明度画：20%（启用）/ 10%（置灰）。浅底淡灰点、深底淡白点，与主题怎么算配色无关。

### 改：顶栏两侧按钮统一走通用振动

- 顶栏的返回键与右上角那一组按钮不再各自 `rememberTick`：`PageHeader` 在**两个槽位的容器**上挂一次（`headerPressTick`），这一页所有顶栏按钮一起带振动，以后新加一颗也自动带上。
- 挂的是不消费事件的指针观察（只看「按下那一刻」），点击仍由里面的按钮自己处理；代价是**置灰的按钮也会振一下**（它此刻确实被按到了，只是不做任何事）。
- 四个自己振过的顶栏按钮（条件执行的「添加」、变量的「新建」、命令页的「重置」、按键功能的「设置」）把那一下撤掉，免得一次按下振两下；`addBranchRule` 那个只为「加不了」时振一下的参数一并删掉（按下那一下已经振过了）。

### 加：调试通道多一个 `net` op（验「注入侧能不能联网」）

- 在 system_server 里分三步试：字面 IP 的裸 TCP、绑默认网络的 DNS、以及一次真正的 HTTP；每步各打一行 W。只在 debug 包存在。
- 实测结论（写进 `docs/device-findings.md` 四十一）：**能连** —— uid 1000 有 `INTERNET`、域允许 inet socket、`HTTP 200`。坑在 DNS：system_server 的 socket 没有进程默认网络，裸 `InetAddress` 会 `UnknownHostException`，必须先用 `ConnectivityManager.activeNetwork` 取网络再 `Network#getAllByName`。
- 顺带记一条否定结论：`plat_sepolicy.cil` 推不出结论（app 域的 inet 规则也不在里面），`runcon` 进那个域又 exec 不了外部程序 —— 这类判断只能在域里真跑。

### 加：注入侧代取网络（底层通道）

- 宿主清单里没有 `INTERNET`，界面代码跑在宿主进程 ⇒ 要出网只能请注入侧代取。新增 `inject/NetChannel`：`ACTION_NET_REQUEST` 问、`ACTION_NET_RESULT` 答，两条都带编号配对。
- 只做 GET、只认 https，正文截到 32 KB（binder 事务上限），连接与读取各 8 秒超时；没有默认网络时直接回「当前没有网络」，不等超时。
- DNS 走 `Network#openConnection`（system_server 的 socket 没有进程默认网络，裸 `HttpURLConnection` 会 `UnknownHostException`）；另起线程、整段兜 `Throwable`、回包在主线程发。
- 广播入口把 `ACTION_NET_REQUEST` 加进白名单并单独分派（不套 `postGuarded`：它自己开线程）。机制写进 `docs/implementation.md`「注入侧代取网络」。
- **待真机验证**：功能通道的来源校验只认宿主 uid，`su` 发的广播会被丢弃 —— 要等宿主侧调用点接上才能端到端跑通。

### 修：Monet 配色下格子的小字是灰的

- 动作格子里那行小字（应用名 / 入口格档位 / 命令间隔）在 Monet 下改用强调色 —— 原来那个 token 在 Monet 里是一档近乎无彩的灰，整页都被壁纸染过，只有它没跟上。
- 其余主题档不动：那一档弱化色是压在中性底子上标定的，换成强调色会糊成一片蓝。

### 改：「强调色」菜单当前那一项行首换成对勾

- 原来那一行保留色块（怕换成对勾就看不出是哪一套色），现在行首一律换成对勾，**颜色仍是那一套的色** —— 形状说「当前是这一项」，颜色说「是哪一套色」。
- 其余菜单的选中行不变（本来就是行首对勾、走主色）。

### 改：「模块设置」改名「按键设置」，挪进「按键操作」卡

- 那一页改的都是「按键怎么工作」（走哪套接口 / 执行时振不振动 / 组合键怎么判），与「按键操作」这张卡是同一件事，摆进「其他」卡反倒像模块自己的设置。
- 首页那一行与那一页的顶栏标题一起改成「按键设置」；摘要改成「接口选择、振动与组合按键」。
- 「其他」卡不再有这一行，其余顺序不变。

### 修：动作网格里每一格都变成同一条自定义命令

- 两组格子（自定义那一组在内建那一组上面）共用了一个可变的起始下标：第二组从第一组**走完之后**的位置起算，于是整片网格读到的都是自定义命令那一列 —— 只在内建与自定义同屏时出现。
- 两组的起始下标改成事先算好的一份（`groupBases`），不再在行内累加。

### 改：动作网格的列数跟着可用宽度走

- 固定两列改成按宽度算：每格最小 150dp，宽了排三列、窄了排两列、再窄落到一列（连一列都放不下的标题落省略号，不再被挤没）。
- 自定义命令那片网格同一套算法（同一个判据一处实现）。

### 加：手势带系统场景时，绑定页与组合编辑页各有一张提示卡

- 按键绑定页每一档手势、以及组合键编辑页，只要当前这一档配了系统场景，就在小标题下面插一张卡：「当前手势有 N 个系统场景判断」。
- 行首一颗分支图标、行尾一颗右箭头，点一下直接进「系统场景」页的对应手势（组合键走它的编辑页）。
- 数量取**启用中**的那几条；一条都没启用时不出现。

### 改：一颗自定义键都没有时「添加组合按键」不可用

- 组合键至少要两颗键：清单里只有内置侧键时那一行置灰，点一下说明原因（`combo.need_key`：先添加一颗按键）。
- 有了任意一颗自定义键、或已经有组合键之后恢复可点。

### 修：暗色下浮层菜单与页面底色太接近

- Monet 那一档原来两种深浅都取页面底色：深色下页面与面板几乎同深，菜单像贴着页面（浅色那一档没问题）。
- 深色改成抬到 `surfaceContainerHighest`（容器里最亮的一档），浅色仍取页面底色。
