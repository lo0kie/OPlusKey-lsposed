## 1.4.0

### 新增

- **独立设置**：每颗键、每一组组合键都能自己决定「接口 / 振动（含强度）/ 执行提示 / 提示文案」。顶上那颗总开关默认关 = 跟随公共设置，打开时先把公共那份抄过来再改 —— 不会出现「开了却看到一堆出厂默认」。
- **长按的两档时序**：「松手才触发」（到点即执行 / 等抬手才执行）与「松手执行额外动作」，单键与组合键都有。两族互不连坐 —— 开着「松手才触发」不影响你还想再补一个动作。
- **滑杆手动输入**：所有滑杆行点一下就能打字输入精确值（延迟 1250ms 这种，拖是拖不准的），打进来的数自动吸到刻度上。
- **组合键编辑页的「自定义命令」**：与「按键绑定」页同一颗悬浮键、同一个落点。
- **系统场景的取值改成选择器弹窗**，一条规则拆成两张卡片（场景 / 命令），分行更清楚。
- **开机提前拉起宿主服务**：原先要等开机后约 15 秒才响应侧键，现在注入侧一起来就主动去拉，这段时间里也能用。
- **按键功能页的全选**：编辑态下顶栏一次勾满按键与组合两列。

### 改进

- **文案统一成一条范式**：`父动作名: 子动作名 - 状态`，应用目标写成 `微信(小窗 扫一扫)`。网格小字、菜单子标题、选择应用页页头、场景动作格、执行提示五处说的是同一句话。
- **网格与抽屉完全同源**：同一格动作在网格里和在抽屉里，清单、文案、图标、小字、二层菜单全都一样。
- **灵感语音拆成「开始 / 结束」两个平级动作**，录屏收成一个动作 + 弹窗选三态（开始 / 结束 / 切换），行尾不再挂一颗小选择器。
- **首页「模块状态」卡**：判据改成与整页总闸同源 —— 只要链路任一段不对，大字就是红的「未激活」，下面直接写清是哪一段、该做什么，不再固定说「系统侧未接管按键」。
- **长按延迟上限** 1000ms → 2000ms。
- **「以小窗口打开」**从 ⋮ 菜单里摘出来，做成顶栏右侧第二颗键。
- **所有滑杆行灰着被点一下都会说清原因**（「先打开使用独立设置」这类），不再一律回落到整页那句。
- **按键执行移出宿主主线程**：命令跑起来时界面不再跟着顿一下。

### 修复

- 修复停用侧键之后，按其它自定义键会把模块页面反复拉起来的问题。
- 修复组合按键列表行尾的启停态显示反了（停用的画着箭头、启用的反而没有标记）。
- 修复一批「设置写了却没生效」：按键独立设置与三档同一事件的字段只写了一半点，落盘有值、执行照旧。
- 修复改名 / 删命令 / 删变量之后漏掉的引用位置（松手动作里留着指向不存在命令的 `cmd:`）。
- 修复几条会让设置页崩或数据被盖的路径：两条命令重名、建页偶发读盘失败、填名字的弹窗被刷新抹掉输入、删除按键写盘失败的判定、导入覆盖时读不懂的原命令库被永久盖掉。
- 修复组合键挂住之后整块键盘不再响应，以及被取消的按键被误判成一次动作。
- 修复「显示失效应用」会顺带放出没有启动图标的系统应用、「显示系统应用」在结束应用那一趟拨了没反应。
- 修复只给双击配了场景时双击永远不执行。
- 修复从组合键进来挑应用，重进这一页选中的那一行不亮。
- 修复从「应用组件」页不选直接返回、抽屉还会弹出来。
- 修复多条命令切进编辑态必崩、行尾三颗按钮叠在一起。

### 移除

- **「三个内置手势同事件时立即执行」整个拿掉**：它把三档的时序改了，而三档本来就该各按自己的时序判（单击等双击窗口、长按过阈值）。配置版本抬到 33，老配置里残留的那两个键按未知键忽略，其余设置不受影响。

### 下载

- `-release` 是正式包，管理器更新到的就是它。
- `-releaseLog` 与正式包完全相同，只是打开了详细日志，排查问题时用。
- `-debug` 是调试包，只用于复现。
